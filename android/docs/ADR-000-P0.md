# ADR-000：P0 原生 Android 骨架、迁移与分页 spike

- 状态：草稿（P0 验证中）
- 日期：2026-10-28
- 范围：`android/` 新工程；旧 Python 工程只作为规格与 oracle
- 目标设备：Redmi Turbo 3（24069RA21C / peridot），Android 16 / API 36，
  build `OS3.0.305.0.WNPCNXM`（adb 实测；用户提供的 `...C11` 与 adb 不一致，以 adb 为准）
- 包名：`com.kacyraho.lightnovel`（已定死，后续改动等于换 app id）
- `compileSdk/targetSdk 36`，`minSdk 26`

## ADR-001：原生 Android，不做 WebView/Python/本地 HTTP

**决策**：从零做 Kotlin + Jetpack Compose 原生 App；APK 内不嵌 Python/Chaquopy，不使用 WebView，不跑本地 HTTP 服务。

**理由**：目标是一个可侧载、离线可读、开机即用的 App；旧 Web 站的运行时依赖（Termux/Python/服务进程）正是要摆脱的部分。

**后果**：翻译引擎、任务恢复、数据迁移都要在 Kotlin 里重新验证；旧 Python 代码只做行为对照，不做运行时依赖。

## ADR-002：A′ v1 = 阅读 + 单章翻译最小闭环

**决策**：v1 先做“导入 → 书架 → 阅读 → 选一章 → 调 DeepSeek → 校验 → 落盘 → 阅读页刷新”的最小闭环。默认模型 `deepseek-flash`，可配置；不实现调度、队列、自动翻译、后台服务、预算刹车、多角色兜底/校对。

**理由**：只读 v1 会留下 Termux 才能翻译的缺口；全量 B 又太重。A′ 先证明最难的 LLM 客户端、校验、边车、原子写路径。

**后果**：A′ 预计 2–3 周；P0-5/P0-6（翻译/导出）放到 A′ 第一周，不塞进 P0。

## ADR-003：身份与迁移以 `lncatalog.py` 为 oracle，Room 为运行时真相

**决策**：
- `id` 是逻辑主键；`storage_dir` 是物理目录；新书两者相同，旧书不一致时打 `id_dir_mismatch`，不重命名。
- 旧 `library.json` 的裸源站 id（如 `117735...`）按 `source-<id>` 归一；真实本地 2 本已验证。
- `slug` 可变，旧值进 `aliases`；异书 slug 冲突走 `choose_slug` 加后缀，不让 alias 抢走赢家 URL。
- Room 为运行时真相；v5 catalog JSON 只做导入/导出适配，未知字段保留在 `legacy_json`。
- 物理目录里的书即使只在 `candidates`，也允许导入，并标 `catalog_candidate`。

**后果**：Kotlin 必须通过从 `lncatalog.py` 行为生成的 golden cases；不能只凭散文实现。

## ADR-004：备份/恢复 verify-first、只增不删

**决策**：
- 只接受 `format 1`；逐文件 sha256；`manifest.bytes` 与实际总量一致；坏一字节整包拒绝。
- zip 路径穿越、非 `novels/data/lnfinder` 根、多余条目、单文件/总量/压缩比超限（zip bomb）全部拒绝。
- 解压到 staging；按书目录原子搬到 `novels/<storage_dir>/`；同名不同内容先 `.bak-<ts>`；内容相同跳过；不 DELETE。
- `data/` 与 `lnfinder/` 原样归档到 `legacy/<backupId>/`，包括 `data/jobs/quarantine/`。
- 章节与阅读状态从备份导入：`chapters` 记录 raw/zh 路径与 `translated/raw` 状态；`data/books/*.json` 导入 shelf/favorite/hidden/progress/opened/finished。

**后果**：恢复是幂等的；失败回滚是 best-effort；磁盘满/跨盘中断仍需真机演练。

## ADR-005：阅读器用 StaticLayout 分页 + HorizontalPager

**决策**：
- 用 `StaticLayout` 按可用宽高切页，`PageSlice` 同时记录字符区间与像素 `top/bottom`。
- `HorizontalPager` 翻页；每页用 `ReaderPageView` 画同一份整章 `StaticLayout`，按 `top/bottom` 裁剪，避免 Compose Text 与分页引擎断行不一致。
- 字号/行距/主题变化时重建 layout 与页；进度按页保存（A′ 接入 Room）。
- v1 必做日文隐藏/显示；逐段对照作为可选验证；竖排、长按选词、TTS 后置。

**后果**：Robolectric 不模拟真实字体度量，字号/宽度重排只在真机 instrumentation 验证。

## ADR-006：PC 浏览器阅读放弃，保留 Exporter seam

**决策**：v1 不做 LAN/HTTP/设备登录；提供 EPUB/备份导出。导出抽象成 `Exporter`（EPUB / backup / future-lan 三种实现），未来加只读端点不改 UI。

**后果**：PC 不能直接看手机书架；若连续 7 天 PC 阅读 ≥3 次，再重新评估只读 LAN 端点。

## ADR-007：没有“卸载前回调”，用首次导出 + 备份时间 + 提醒

**决策**：Android 不向被卸载应用发送卸载回调；改为首次导入后强制走一次导出向导、设置页常驻 `last_backup_at`、周期提醒、升级前提示。自动每日备份放 D 阶段。

**后果**：不能承诺“卸载前一定备份”；用户需要在提醒出现时主动导出。

## P0 当前结果

- 单元测试：30 个，0 失败；真实本地 2 本备份（`.tmp/fixtures`，未提交）导入 `books=2, chapters=184, readStates=2, orphans=0, conflicts=0`。
- `lintDebug`：0 errors，9 warnings（依赖新版本提示、`allowBackup` 弃用）。
- `app-debug.apk` 约 13.5MB；无 Python/Chaquopy/WebKit 条目；仅 `INTERNET` 权限。
- 真机（Redmi Turbo 3，1220×2712 / 480dpi）：
  - `adb install` 成功；手动 `am start` 冷启动 debug 3 次：920 / 666 / 621ms，中位 666ms；无 `AndroidRuntime` 崩溃。
  - `PaginatorDeviceTest` 通过：40 段文本下，36px/720×1200=10 页，72px=32 页，900×1200=14 页，360×1200=30 页——真实字体度量下字号/宽度会改变页数。
  - Compose UI instrumentation 在 HyperOS 上被“Abort background activity starts”拦截，`MainActivityTest`/`ReaderScreenTest` 跳过；这不是 App 崩溃，需 AOSP/模拟器或开启后台活动启动许可。手动启动 Activity 正常到前台。

## 未决/风险

- 真实 19 本手机备份尚未验证；迁移格式分布需以真实备份为准。
- 章节状态目前只按文件存在性判断，尚未读边车 `complete/partial`/hash。
- 回滚未覆盖磁盘满、跨盘移动中断；zip 符号链接/加密 zip 未覆盖。
- 书架/导入/设置页尚未做；当前 UI 是分页示例（已能翻页、调字号、显示页码）。
- 120Hz 实际翻页帧时间未测：Compose instrumentation 在 HyperOS 被拦截，且不做屏幕点击/滑动操作；留待 AOSP/模拟器或用户手动体验。
- release 签名、arm64-only、R8 尚未配置。
