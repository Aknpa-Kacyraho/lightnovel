# Ka小说家 Android 信息架构与导航改造方案（IA v1）

> 读码基线：`0.7.2-p1`，Compose 单 Activity + Navigation Compose，Room v2。本文只做信息架构、导航与页面分层设计，不写函数级实现。
> 参考代码位于 `.tmp/auto-novel-reference`，仅只读研究；只吸收交互模式，不复制 GPL 代码。

## 目标

- 把用户的三个核心意图放进稳定的一级入口：**继续读、找新书、管理自己**。
- “发现”升为底栏一级分类；书籍详情与章节目录彻底分开；标签、作者、来源等实体可点。
- 书架、设置、任务中心按“常用 / 低频 / 异常”分层，默认界面只保留高价值信息。
- 导航允许底层重构，但按 P0/P1/P2 小步迁移，每一步有独立验收，不做一次性推倒重来。
- 保持本地优先：无登录、无远端同步、无评论/论坛、无服务器依赖。

## 非目标

- 不引入账号登录、Wenku、云收藏、阅读历史同步、评论、论坛、社区或服务器推荐。
- 不在本阶段重写阅读器分页引擎、翻译管线、Room 导入/备份格式。
- 不做封面抓取、CDN、复杂推荐算法、后台下载服务、推送通知。
- 不为了“看起来功能多”增加入口；P0 不新增任何非必要页面。
- 不复制参考项目的 Vue/TS/CSS 模板，也不移植其评论、登录、文库等带服务端假设的模块。

## 设计原则

1. **一级入口只放三种意图**：继续读（书架）、找新书（发现）、管理自己（我的）。任务和设置是支撑能力，不占一级。
2. **一屏只做一件事**：详情负责“决定读不读/从哪读”，目录负责“选章”，阅读器负责“读”。不把三者叠在一个滚动列表里。
3. **状态跟着 Tab 走**：每个 Tab 有独立返回栈；跨 Tab 跳转（标签/作者→发现）是显式动作，不销毁来源 Tab 的详情和滚动位置。
4. **渐进披露**：低频操作放 overflow/子页；技术参数、遗留服务、诊断信息放“高级”；常用状态用摘要行展示。
5. **空态、错误态、进行中都是正式界面**：给出下一步动作，不用一句“暂无数据”结束。

## 目标信息架构

### 底部 Tab（3 个）

| 顺序 | 名称 | 图标语义 | 职责 |
| --- | --- | --- | --- |
| 1 | 书架 | 书堆/书架（沿用 `ic_nav_library`） | 默认落地；继续阅读、最近阅读、全部书籍、本地搜索/筛选/排序。 |
| 2 | 发现 | 指南针（新增 `ic_nav_discover`） | 一级找书：搜索、周榜、标签、链接加书、来源预览。 |
| 3 | 我的 | 人像（新增 `ic_nav_me`） | 任务入口、备份状态、阅读/外观/翻译/数据/关于/高级设置。失败翻译任务在“我的”上显示角标。 |

- **不设第 4 个“任务”Tab**：任务中心是异常与长任务控制台，不是日常浏览目的地；空队列时它只会制造一个死 Tab。改为“我的”顶部状态卡 + 失败角标，详情/阅读器内也可直达。
- 底栏文案保持两字，图标 + 文字，选中态用 primary；不做动态增减 Tab，避免导航不可预测。
- “发现”必须是顶级：它是独立的“找书→加书→读”循环，不是书架的附属动作；它有自己的查询/结果/来源状态；它也是标签/作者点击后的统一落点。放在顶栏小按钮既难发现，也和“导入”等工具按钮混在一起。

## 路由表

> 路由名为逻辑名；参数统一 URL 编码。`bookId` 为本地 Room id，`provider/id` 为上游源标识。

| 路由 | 入口 | 参数 | 底栏 | 返回栈 / 恢复 |
| --- | --- | --- | --- | --- |
| `library` | 启动 / 底栏 | — | 显示 | 书架根；搜索、筛选、排序、滚动位置保存。 |
| `library/book/{bookId}` | 书架行、继续阅读卡、发现“查看” | `bookId` | 显示 | 返回书架并保留滚动；详情滚动位置按书保存。 |
| `library/book/{bookId}/chapters` | 详情“目录” | `bookId` | 隐藏 | 返回详情；目录滚动、搜索词、排序按书保存。 |
| `discover` | 底栏 | — | 显示 | 发现根；推荐/标签状态保留；根返回落到书架。 |
| `discover/search` | 搜索框、标签、作者 | `q`、`mode=keyword\|tag\|author`、可选 `provider` | 显示 | 单实例搜索页；换词不压栈；返回发现上一屏，不返回详情。 |
| `discover/source/{provider}/{id}` | 结果卡 | `provider`、`id` | 显示 | 返回结果页；加入书架后停留本页，用 Snackbar 提供“查看”。 |
| `discover/rank/{provider}` | 周榜“更多” | `provider`、可选 `type` | 显示 | P2；返回发现。 |
| `me` | 底栏 | — | 显示 | 我的根；状态卡与分组摘要；根返回落到书架。 |
| `me/tasks` | 我的任务卡/角标、详情翻译覆盖 | 可选 `bookId` | 隐藏 | 返回我的；筛选状态保存。 |
| `me/settings/{group}` | 我的分组行 | `group=reading\|appearance\|translation\|data\|about\|advanced` | 隐藏 | 返回我的；未保存修改需确认。 |
| `reader/{bookId}/{idx}` | 继续阅读、目录、任务 | `bookId`、`idx` | 隐藏 | 阅读器单实例；换章替换当前条目，返回目录/任务/书架。 |

- 书架搜索**不单独建路由**：顶栏搜索图标展开为内联搜索，就地过滤，保留列表滚动；与“发现”的在线搜索明确区分。
- 链接加书**不单独建路由**：发现页 overflow / 空态打开底部 Sheet，只有一个输入框。
- 详情显示底栏（它仍是“浏览层”），目录/阅读器/任务/设置子页隐藏底栏（“专注层”）。规则按目的地层级判断，不再用当前 `route == 顶层字符串` 的等值判断。

## 导航与状态规则

1. **Tab 切换**：每次切 Tab 保存当前栈并恢复目标栈；同一 Tab 重复点击回到该 Tab 根，不重复压栈。
2. **底栏可见性**：浏览层（三个 Tab 根、发现搜索/来源预览、书籍详情）显示；专注层（目录、阅读器、任务中心、设置子页）隐藏。隐藏/显示不得改变页面内部状态。
3. **跨 Tab 跳转（标签/作者）**：保留来源 Tab 的详情与滚动；切到发现并打开对应搜索。返回只回发现上一屏，不把用户弹回详情；再点“书架”应恢复原详情页。
4. **发现加书**：不自动跳转；成功后原位显示“已在书架”，Snackbar 给“查看”。用户主动点“查看”才切到书架详情。这样发现结果、查询、滚动都不丢。
5. **阅读器换章**：上一章/下一章替换当前阅读器条目，不让返回栈累积 N 章；系统返回先关阅读器面板，再回到目录/任务来源。
6. **根返回**：在发现/我的根按返回回到书架；在书架根按返回退出。不要在根拦截返回做“再按一次退出”的弹窗。
7. **状态恢复**：列表滚动、筛选、排序使用 `rememberSaveable`/SavedStateHandle；在线搜索结果只恢复查询并重新请求，不持久化大列表；阅读进度以 Room 的锚点为准。加书成功、导出完成等一次性事件用事件通道，不放进会重放的 UI 状态。
8. **禁止**：任何“打开书”都不得 `popUpTo(discover){inclusive=true}`；任何详情/目录跳转都不得清空来源 Tab 栈。

## 书籍详情页

结论：**详情只负责决策，目录只负责选章；手机端用两个独立页面，不把目录塞进详情 Tab。**

| 区域 | 内容 | 默认 / 交互 |
| --- | --- | --- |
| 顶栏 | 返回、书名（滚动后淡入）、overflow | overflow 放低频操作，不放大按钮。 |
| Hero | 文字封面（首字 + 来源色块；当前无封面字段）、中文书名、日文书名、作者、来源徽标、连载状态/话数 | 作者可点→发现按作者搜索；日文书名可长按复制。 |
| 标签 | 本地化标签优先，缺失回落原文；FlowRow，最多 8 个 + “更多” | 每个标签可点→发现标签搜索；空标签整段隐藏。 |
| 主操作 | “继续阅读 第 X 章”或“开始阅读”；收藏星标；overflow（缓存全部/导出 EPUB/打开源站） | 继续阅读是唯一主按钮；收藏是开关；下载/导出不占顶栏。 |
| 上次读到 | 进度条 + “第 X 章 · 第 N 段” + 更新时间 | 点击回阅读器；无进度时隐藏。 |
| 简介 | 默认 6 行，渐变遮罩 + “展开全部” | 无简介显示“暂无简介”并给源站入口；不要把原文和译文重复堆叠。 |
| 信息 | 翻译覆盖（已译/总章）、来源、本地/在线、最近更新 | 翻译覆盖可点→任务中心按书筛选（P1）。 |
| 目录入口 | “目录 · 共 X 章”、第一章/最新章节摘要、“查看全部” | 只做入口，不渲染完整章节列表。 |

- **上次读到/收藏/下载/导出放置**：上次读到 = 进度卡；收藏 = 主操作星标；下载全部 = overflow + 详情内进度条；导出 EPUB = overflow。备份是全局能力，放“我的/数据”，不放进单书详情。
- **本地书 vs 在线书**：
  - 本地书：来源徽标“本地导入”；无“缓存全部/刷新/打开源站”；保留收藏、继续阅读、导出 EPUB、目录；标签/作者有则显示。
  - 在线书：显示平台徽标、话数、源站入口；有“缓存全部章节”及进度；翻译覆盖可见；目录中显示生肉/未译全/失败状态。
  - 两者都使用同一套 hero/操作/进度组件，差异只由能力开关控制，不复制两套页面。
- **宽屏**：手机端详情 → 目录是 push；平板/横屏（P2）可做左详情、右目录双栏，但手机路径不变。

## 章节目录页

- 顶栏：返回、书名（小字）、章数、搜索图标、排序（正序/倒序）、筛选（全部/已译/未译/失败）。
- 首屏：若有进度，顶部固定“上次读到 第 X 章”卡片；进入时自动滚到当前章，但用户手动滚动后不再抢夺位置。
- 行内容：章序号、标题（译文优先）、翻译状态、当前章高亮；点击进阅读器。目录不重复简介、标签、作者、下载大按钮。
- 空态：本地书“这一本还没有章节文件，可重新导入”；在线书“目录为空，去源站查看/刷新目录（P2）”。
- 搜索/排序/滚动位置按 `bookId` 保存；返回详情再进来应恢复原位。

## 书架页降噪

- 顶栏：`书架` + 搜索图标 + overflow（导入备份、排序）。移除“发现”按钮；发现由底栏承担。
- 搜索：点图标展开内联搜索，搜标题/作者/标签；保留滚动；空结果提示“清除筛选”或“去发现找书”。不在书架放第二个在线搜索入口。
- 备份提醒：仅当“有书且从未备份”时显示一条可关闭提示；操作“去备份”跳我的/数据；关闭后 7 天内不再出现（P1 持久化）。不要每次进书架都顶一条警告。
- 继续阅读：横向 1–5 本最近有进度的书，显示书名、第 X 章、进度；点击直接进阅读器。无最近阅读则整段隐藏，不占位。
- 全部书籍：标题 + 数量；筛选 Chip 一行可横滚：全部/在读/想读/读完/收藏；排序菜单：最近阅读（默认）/最近添加/标题/作者。
- 行样式：文字封面、书名、作者、进度、本地/在线徽标；去掉每行常驻收藏星。收藏/标记书架/隐藏放行尾 overflow 或长按选择模式（P2）。
- 导入：overflow 与空态都提供；导入中显示进度条；完成后留在书架，提示“建议导出一次备份”。
- 空态：无书时主按钮“导入备份”，次按钮“去发现”；有筛选/搜索无结果时只给“清除筛选/搜索”，不误导去导入。
- “最近阅读”定义：`progressIdx > 0` 且 `updatedAt` 较近；当前 `openedAt` 未被写入，P0 先用 `updatedAt`，P1 再决定是否在打开阅读器时写 `openedAt`。
- 当前没有设置 `shelf` 的入口：P1 在详情 overflow 提供“标记为 想读/在读/读完/弃文”，首次打开阅读器可自动标“在读”；不要自动标“读完”。

## 发现页（一级）

- 首页：顶栏 `发现` + 一个搜索入口 + overflow（从链接添加）。不再常驻“关键词输入 + 搜索按钮 + 链接输入 + 加书按钮”两组表单。
- 内容分节：`本周推荐`（按来源分组，带排名/来源徽标，6–8 条/组）→ `热门标签`（FlowRow，10–12 个）→ `按来源浏览`（P2）。每组有“更多”，不把两个来源的推荐混成无来源的 12 条。
- 搜索页：一个输入框 + 来源筛选 Chip（全部/成为小说家/Kakuyomu）+ 结果计数；提交后保留旧结果并在顶部显示线性进度，首次加载才用骨架屏。
- 链接加书：底栏 Sheet，单输入框 + 粘贴按钮 + 支持格式示例；识别 Kakuyomu / 成为小说家链接或数字 ID；错误就地提示，不关闭 Sheet。
- 结果卡：中文标题（缺失显示日文）、可点作者、来源徽标、话数、两行简介、最多 3 个标签 + 更多；主按钮“加入书架/已在书架”，次按钮“详情”。整卡点击进来源预览，避免卡片点击和按钮语义冲突。
- 标签/作者：详情、发现卡片、来源预览中均可点；标签用 `mode=tag`，作者用 `mode=author`，跳到发现搜索。译文标签缺失时用原文查询，保证可点。
- 加入书架后**停留原页**，卡片变“已在书架”，Snackbar：“已加入书架 · 查看”。不自动打开详情或阅读器；这是修复当前 `DiscoverScreen.kt:64-69` 的关键。
- 状态设计：

| 状态 | 展示 | 动作 |
| --- | --- | --- |
| 首次加载 | 3 张骨架卡，保留页面头部 | 可取消/等待，不显示全屏转圈。 |
| 搜索中 | 旧结果 + 顶部进度条，按钮禁用防重复 | 取消上一次请求。 |
| 部分来源失败 | 该来源位置显示“暂时不可达” | 单源重试；其他来源结果保留，不清空。 |
| 全部失败 | 错误面板 + 网络提示 | 重试 / 链接加书 / 去书架。 |
| 无结果 | 关键词建议 + 当前筛选说明 | 清除筛选 / 换日文关键词 / 链接加书。 |
| 翻译中 | 卡片角落“翻译中”小标签，原文可见 | 加入/阅读不被阻塞；失败回落原文。 |
| 加书成功 | 原位状态 + Snackbar | 查看书籍 / 继续浏览。 |

- 搜索历史、按标签的落地页、作者页是 P2；P0 只保证标签/作者能到搜索结果。

## “我的”与设置分组

“我的”不是又一个设置长页，而是**状态 + 分组入口**：

- 顶部：应用名、版本、`本地优先` 一句话。
- 状态卡：备份（上次时间/从未备份）、翻译任务（进行中/失败数）、缓存（大小）。每张卡可点进对应子页。
- 分组入口：阅读、外观、翻译、数据、关于、高级。每行只显示“当前值摘要”，例如“字号 18 · 行距 1.7 · 宋体”，点进子页再改。

| 分组 | 常驻内容 | 收进子页/高级 |
| --- | --- | --- |
| 阅读 | 字号、行距、段距、边距、字体、常亮、默认译文/原文/双语、翻页/滚动 | 实时预览、恢复默认；无危险操作。 |
| 外观 | App 主题 | 跟随系统（P2）。 |
| 翻译 | 服务是否配置、模型、Key 状态、测试连接 | Base URL、原始模型参数放“高级”；Key 输入只在配置页。 |
| 数据 | 导出备份、导入备份、上次备份、缓存大小/清理 | 存储路径、文件计数、诊断导出放高级。 |
| 关于 | 版本、来源站点说明、开源许可、隐私说明 | 构建信息/日志。 |
| 高级 | 入口本身带说明与风险提示 | Novelia 遗留服务、端点和模型、诊断、重置引导、实验开关。 |

- **必须常驻可见**：备份状态、翻译服务未配置提醒、版本、阅读字号入口；其余技术项不得出现在一级。
- **必须隐藏**：DeepSeek Base URL/原始模型参数、Novelia 服务器与账号、缓存文件级信息、调试日志。现有 `SettingsViewModel` 的 Novelia 登录/收藏/历史导入能力不进入常规设置；P2 评估移除或明确标“遗留，不推荐”。
- **保存语义**：阅读/外观开关即时生效；Key、端点、模型等凭据/网络配置显式“保存”，离开前拦截未保存修改。设置项变更不能重建整个 NavHost。
- 现有设置页把“日本源站说明”“翻译模型”“缓存”“备份”混在一条长滚动里；分组后每页只保留一个主题。

## 任务中心定位

任务中心 = **异常与长任务的控制台**，不是第二个首页，也不是翻译日志归档。

| 应该解决 | 不应该放进去 |
| --- | --- |
| 哪些章节正在翻译、失败、未完成 | 阅读历史、收藏、推荐、书架浏览 |
| 失败原因、重试、取消、跳到精确章节 | 已完成成功任务的长期归档 |
| 按书聚合，避免 100 条平铺 | 所有章节的普通状态列表 |
| 与详情/阅读器互相跳转 | 设置、账号、文件管理器 |

- 结构：顶部状态摘要（进行中/失败/未完成）→ 筛选 Chip → 按书分组的可展开列表 → 章节行（状态、错误摘要、查看/重试/取消）。
- 角标：只在“我的”上显示失败数；进行中数放状态卡。不要给完成/成功也加角标。
- 联动：任务章节 → 阅读器精确章节；任务分组 → 书架详情；详情“翻译覆盖” → 任务中心按书筛选；阅读器翻译失败 → 重试 + “查看任务”。
- 下载全部目前是前台操作（`ChapterListViewModel.downloadAll`），P0 不冒充后台任务；进度留在详情内。等下载变成可恢复任务后（P2），再进入任务中心。

## 风险与缓解

| 风险 | 表现 | 缓解 / 验证 |
| --- | --- | --- |
| 导航重构 | 路由拼错、底栏在错误页面显示、深链空白 | 路由常量集中；底栏按层级推导；加导航矩阵测试（每个 Tab 根/详情/目录/阅读器）。 |
| 返回栈 | 发现被清空、阅读器按章累积 N 层、返回跳过目录 | 禁止 `popUpTo(discover){inclusive}`；阅读器换章替换条目；逐路径手测返回。 |
| 状态恢复 | 旋转/进程重建丢滚动、搜索词、筛选 | `rememberSaveable`/SavedStateHandle；列表状态按 key 保存；进程死亡测试；阅读进度以 Room 锚点为准。 |
| Compose 重组 | 底栏显隐导致跳动、列表整段重组、搜索输入卡顿 | 状态提升到 ViewModel；`LazyColumn` 稳定 key；`derivedStateOf` 算计数；网络/排序不在组合期执行。 |
| 测试 tag 变更 | `library-screen`、`chapter-list-screen`、`settings-screen`、`reader-screen` 失效 | 新页面保留旧 tag 作为根 tag 或同步更新测试；集中 `UiTags`；跑 connected tests。 |
| DAO/迁移 | 最近排序/书架标记引入新查询或字段，旧库升级失败 | P0 尽量内存排序；P1 若加索引/字段，补 Room v3 迁移与 `MigrationTest`；备份前后指纹核对。 |
| 网络与翻译 | 单源失败清空整页、翻译结果串台、重复加书 | 按来源独立状态；查询 token 校验；加书幂等；旧结果保留到新结果到达。 |
| 范围膨胀 | 设置重复、任务中心变成日志页、发现堆功能 | P0 只做本表 5 项；新增入口必须说明“解决哪个现有问题”；不做登录/同步/评论。 |
