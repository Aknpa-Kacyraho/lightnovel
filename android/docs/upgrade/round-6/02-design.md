# Round 6 · 设计师视角升级指南（v1.2.2）

> 目标：让阅读界面「像一本书」，让进度「一眼可见但不打扰」。
> 只加两条细线与一个点击手势，不重排导航。

## 1. 设计问题

### D1. 沉浸需要更轻的入口（P1）

现在只有菜单里的「沉浸阅读」。阅读器的核心动作应该是「点一下正文」——
这也是多数阅读器的肌肉记忆。顶栏/底栏的隐藏不该是设置项。

**方案**：
- 单击正文空白 → 切换沉浸（隐藏顶栏、状态横幅、模式行、底栏）；
- 查询模式下点中词条 → 打开词条卡，不切换；
- 横向滑动 → 翻页，不切换；
- 沉浸态保留底部「退出沉浸」按钮，点击恢复。

**约束**：不给正文加可见按钮；不改 `HorizontalPager` 手势。

### D2. 首次沉浸要有解释（P2）

误触进入沉浸的用户会以为界面坏了。进入沉浸时显示 3 秒提示
「单击正文或点底部按钮退出沉浸」，只在本章第一次进入时出现。

**视觉**：`labelSmall`，`secondaryColor.copy(alpha = 0.8f)`，居中偏下，
不遮正文首行；不做卡片、不加背景。

### D3. 进度细线（P1）

底栏页码是文本，缺少连续感。

**方案**：
- 底栏 `Row` 上方加 **2dp** 进度线，全宽；
- 已读部分 `textColor.copy(alpha = 0.28f)`，未读部分透明；
- 翻页模式：`(pageIndex + 1) / pages.size`；
- 滚动模式：`(scrollParagraph + 1) / blocks.size`；
- 没有内容（0 页/0 段）时为 0，不显示异常。

**理由**：0.28 alpha 在纸白/夜间都不抢字；2dp 不产生「进度条 UI」的强存在感。

### D4. 继续阅读卡的进度（P2）

书架横向「继续阅读」卡与列表卡信息密度不一致。

**方案**：在「第 N 话」下方加 2dp 进度线，颜色 `primary.copy(alpha = 0.45f)`，
宽度随卡片。不增加文字、不加百分比。

### D5. 不改的东西

- 底栏「上一章/目录/下一章」的位置与文案；
- 顶栏的返回/更多；
- 阅读器的字号、行距、纸色；
- 任何翻译状态逻辑。

## 2. 验收

- [ ] 普通模式单击正文：顶栏与底栏隐藏；再点恢复。
- [ ] 查询模式点词：词条卡打开，不进入沉浸。
- [ ] 横向滑动：只翻页，不切换沉浸。
- [ ] 首次沉浸提示 3 秒后消失，不重复。
- [ ] 翻页/滚动模式进度线与页码一致。
- [ ] 继续阅读卡进度线与列表卡视觉一致（更淡）。
