# Round 6 · 用户视角升级指南（v1.2.2）

> 基线：1.2.1（versionCode 42）。前两轮解决了刺眼、常驻提示、深色层级。
> 本轮处理「读的时候界面感太强」与「不知道自己读到哪」。

## 1. 用户真实会遇到的 4 个问题

### U1. 想专心读，只能去菜单里找「沉浸阅读」（P1）

`ReaderRoute.kt:701-727`：沉浸模式只能从「更多 → 沉浸阅读」进入，退出靠底部
「退出沉浸」按钮。阅读中想临时藏一下顶栏/底栏，要两次点击。

**用户感受**：界面一直在，正文像嵌在工具里，不像一本书。

**本轮要求**：单击正文空白处切换沉浸；查询模式下点中词条仍打开词条卡，
不触发切换。横向滑动翻页不受影响。

### U2. 底栏只有页码文字，没有进度感（P1）

底栏是「上一章 / 目录 / 第 3 页 · 5/120 · 译文 / 下一章」。
用户知道页码，但不知道本章还剩多少。

**用户感受**：翻页时缺少「快读完了」的反馈，长章容易烦躁。

**本轮要求**：底栏上方加一条 2dp 的本章进度细线，低对比、不抢正文；
滚动模式按段落进度，翻页模式按页进度。

### U3. 书架「继续阅读」卡没有进度（P2）

`LibraryScreen.kt:410-445` 的横向卡片只显示「第 N 话」；下方列表卡有进度条。
同一个书架，两种信息密度。

**本轮要求**：继续阅读卡补一条与列表一致的细进度条，不增加文字。

### U4. 沉浸模式没有「怎么退出」的提示（P2）

第一次误触进入沉浸后，只有底部一个「退出沉浸」按钮；用户可能以为界面坏了。

**本轮要求**：进入沉浸时用 Snackbar 提示一次「单击正文可退出沉浸」，
只在本章第一次进入时出现，不重复打扰。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 单击正文切换沉浸 | 普通模式点击 → 顶栏/底栏消失；再点恢复 |
| U2 | 底栏有本章进度细线 | 翻页/滚动都随进度变化 |
| U3 | 继续阅读卡有进度条 | 与列表卡一致 |
| U4 | 首次沉浸有退出提示 | 只出现一次，不阻塞阅读 |

## 3. 明确不做

- 不做点击左右区域翻页（Pager 已支持滑动，避免误触）。
- 不做自动隐藏工具栏的定时器（用户控制，不猜测）。
- 不改顶栏/底栏的功能项，不改菜单结构。
