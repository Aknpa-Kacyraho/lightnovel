# Round 2 · 设计师视角升级指南（v1.1.0）

> 目标：不新增页面、不换视觉语言，只修「主次、路径、分组」。
> 判断标准：新用户 10 秒内知道下一步；老用户少找一层。

## 1. 设计问题

### D1. 空态没有主次（P0）

`LibraryScreen.kt:313-345`：标题「还没有书」+ 一段说明 + 三个入口
（实心「导入备份」、文字「导入 TXT / EPUB」、文字「去发现」）。

问题不在按钮数量，而在**叙事顺序**：说明先讲备份，主按钮也是备份，但大多数新用户
并没有旧备份。视觉权重与真实概率相反。

**方案**：

```text
        还没有书
第一次用？去发现找一本日文轻小说。
有旧手机或旧备份？先导入备份，再继续读。

        [ 去发现 ]            ← 唯一实心按钮
   导入备份 · 导入 TXT / EPUB   ← 一行两个文字入口，中间用 · 分隔
```

- 标题保持 `titleMedium`；两行说明 `bodyMedium` / `onSurfaceVariant`；
- 主按钮用默认 `Button`，不放大；
- 次级入口用 `TextButton` 放同一 `Row`，小屏可换行；
- 已移出 / 有筛选的空态保持现有「清除筛选」逻辑，不套用本方案。

### D2. 设置页没有「到达感」（P1）

从书架点「去设置」，落在设置页顶部。用户看不到「导出备份」，也不知道还要滚多久。
设置页是单列 `Column + verticalScroll`，没有目录、没有锚点。

**方案**：

- 书架备份提醒的「去设置」带参数 `focus=backup`；
- 设置页滚动到「数据」分组，并给该分组 2 秒 `primaryContainer` 边框/底色高亮
  （用 `animateColorAsState` 淡出，不弹窗、不新增文案）；
- 手动进入设置不带参数，行为不变；
- 不新增设置目录页。

### D3. 阅读器「更多」是 13 项平铺（P1）

`ReaderComponents.kt:405-501` 的顺序是历史堆叠：字号 → 纸色 → 翻译 → 润色 → 本书设定
→ 世界线 → 附近词条 → 查询模式 → 本章信息 → 术语表 → 当前段落 → 沉浸阅读。
功能之间没有关系提示，世界线被夹在中间。

**方案**：四组，组间 `HorizontalDivider`，组标题不可点击：

| 组 | 项 |
| --- | --- |
| 阅读 | 字号减小、字号增大、切换纸色、沉浸阅读 |
| 翻译 | 翻译本章 / 重译本章、润色本章、本章信息 |
| 资料 | 本书设定、附近词条、查询模式、术语表、当前段落 |
| 世界线 | 编辑并生成世界线 |

- 组标题 `bodySmall` + `onSurfaceVariant`，左 padding 与菜单项文字对齐；
- 菜单项文字、顺序、禁用条件不变；
- 菜单仍可滚动，不改成全屏 Sheet（本轮控制风险）。

### D4. 任务统计不可点（P2）

统计数字现在是纯文本，但用户看到「失败 3」的第一反应是点它。
把数字做成可点筛选，选中态用 `primary` 文字 + `primaryContainer` 底，未选中用
`onSurfaceVariant`；不新增大按钮。

### D5. 一致性保持

- 书架「移出」与任务「忽略」都已是 Snackbar + 撤销，文案格式保持
  「已……，……」+ 动作「撤销」。
- 所有新增文案使用中文全角标点；动词开头；不出现「操作成功」。

## 2. 约束

1. 不新增颜色 token；高亮与选中态只用 `MaterialTheme.colorScheme`。
2. 不新增图标；不引入新依赖。
3. 触控目标 ≥44dp；空态按钮行在 360dp 下不截断。
4. 深浅色、8 套主题下都要检查 `primaryContainer` 文字对比度。
5. 大字体会让空态说明换行，允许增高，不允许省略号截断关键路径。

## 3. 验收

- [ ] 空态只有 1 个实心按钮；两条路径文案完整可读。
- [ ] 从备份提醒进入设置，首屏能看到「导出备份」，高亮 2 秒后消失。
- [ ] 阅读器菜单有 4 个组标题、3 条分隔线，所有原功能仍可达。
- [ ] 任务统计点击后筛选立即变化，选中态可见。
- [ ] 360dp + 字体 1.3x 下无按钮文字被截断。
