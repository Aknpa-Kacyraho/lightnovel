# Round 2 · 用户视角升级指南（v1.1.0）

> 基线：1.0.4（versionCode 38）。Round 1 已修掉误触与无障碍硬伤。
> 本轮只做「第一次用不迷路、常用动作少一步」。

## 1. 用户现在会卡在哪

### U1. 第一次打开，空书架给三个平级按钮（P0）

`LibraryScreen.kt:340-343`：空态是「导入备份」主按钮 +「导入 TXT / EPUB」+「去发现」
两个文字链接。但文案只说「导入备份，或去发现找一本日文轻小说。」

新用户分不清：我是「有旧备份」还是「从零开始」？TXT/EPUB 和「备份」又是什么关系？

**要求**：空态改成两条明确路径，而不是三个按钮：

```text
还没有书
第一次用？去发现找一本日文轻小说。
有旧手机或旧备份？先导入备份，再继续读。

[ 去发现 ]        ← 主按钮
导入备份 · 导入 TXT / EPUB   ← 次级文字入口
```

**验收**：空态只有一个实心按钮；两条说明各一行；360dp 下不折成四行。

### U2. 备份提醒点了「去设置」，还要自己找（P1）

`LibraryScreen.kt:204` 的「去设置」调用 `onOpenSettings`，进入设置页顶部（外观）。
用户要自己滚过「外观 / 阅读 / 翻译 / 显示 / 翻译范围」才看到「数据」。

**要求**：从书架提醒进入设置时，直接滚到「数据」分组，并给 2 秒高亮边框；
手动进入设置仍停在顶部。

**验收**：点「去设置」后「导出备份」按钮在首屏可见；返回后再进设置没有残留高亮。

### U3. 阅读器菜单一屏十几项，找不到「世界线」（P1）

`ReaderComponents.kt:374-500` 的菜单依次是：翻译、字号±、纸色、朗读、本书设定、
资料库、润色本章、术语高亮、本章信息、自动翻译、查询模式、世界线……
没有分组，没有分隔，靠用户逐行扫。

**要求**：分成四组并加小标题：

- **阅读**：字号、纸色、朗读、查询模式、自动翻译
- **翻译**：翻译本章、润色本章、本章信息
- **资料**：本书设定、资料库、术语高亮
- **世界线**：世界线、从本章开世界线（若入口在此）

**验收**：任意功能不超过两次扫视；分组标题用 `bodySmall` + `onSurfaceVariant`；
不新增图标。

### U4. 任务页统计只是数字，不能点（P2）

顶部「失败 3 / 未译全 2 / 进行中 1」只是展示，用户想处理失败还得点筛选 chip。

**要求**：统计项可点，点了直接切到对应筛选；当前筛选的统计项有选中态。
「全部」仍由现有筛选 chip 承担。

**验收**：点「失败 3」→ 列表只剩失败任务；再点一次回「全部」。

### U5. 章节列表的「翻译」与「自动翻译」关系不清（P2，本轮只记录）

`ChapterListScreen` 与阅读器设置里都有翻译入口，用户不知道哪个会花钱。
**记录到 Round 3**：统一在按钮上标注「将翻译 N 章」。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 空态两条路径、一个主按钮 | 手动看 360dp / 大字体 |
| U2 | 备份提醒直达数据分组 | 点一次就看见「导出备份」 |
| U3 | 阅读器菜单四组 | 菜单可滚动、分组标题清楚 |
| U4 | 统计可点筛选 | 点数字即筛选 |

## 3. 明确不做

- 不做新手引导页、不做账号、不做云同步。
- 不改底栏、不改四个 Tab 的信息架构。
- 不动翻译管线与费用模型（Round 3）。
