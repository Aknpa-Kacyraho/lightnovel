# Round 11 · 设计师视角升级指南（v1.4.1）

> 目标：搜索要「快、准、能回去」。不新增一级页面，沿用阅读器 BottomSheet 语言。

## 1. 设计问题

### D1. 搜索入口放在「资料」组（P1）

阅读器菜单已四组；「搜索本书」属于查找资料，放「资料」组，与「术语表」「书签列表」相邻。

**方案**：文案固定「搜索本书」，不加图标；点击打开搜索 Sheet。

### D2. 搜索 Sheet 的结构（P0）

```text
搜索本书                          [关闭]
[ 输入关键词…                    ]
搜索范围：译文 · 30 条上限
─────────────────────────────
第 3 话 · 雨夜的表白
…那句话我到现在还记【得】。雨声…
─────────────────────────────
第 12 话 · 旧校舍
…楼梯尽头有一扇不该存【在】的门…
```

- 输入框 `OutlinedTextField`，单行，自动聚焦并弹键盘；
- 结果行：章节标题 `titleSmall`，片段 `bodySmall`，关键词用 `primary` 加粗；
- 空态：「没有找到；换个关键词试试。」；
- 搜索中：「正在搜索…」+ 小进度条（`LinearProgressIndicator`），不阻塞输入。

### D3. 结果片段的高亮（P1）

只高亮关键词，不做整段底色；最多前后各 20 字，超出用省略号。
高亮用 `AnnotatedString` + `SpanStyle(color = theme.text, fontWeight = Bold)`，
背景色不新增。

### D4. 跳转与关闭（P1）

点击结果：关闭 Sheet → 跳转。同章定位到段落；跨章跳到目标章开头，
并保留一次「再次搜索」的成本（V1 接受）。

### D5. 不改的东西

- 阅读器菜单分组与顺序（只加一项）；
- 分页、翻译状态、书签逻辑；
- 章节列表的搜索（那是目录内搜索，不是正文）。

## 2. 验收

- [ ] 「更多 → 资料」出现「搜索本书」。
- [ ] 输入后 300ms 出结果；清空输入结果清空。
- [ ] 每条结果有章节、片段、关键词高亮、范围标注。
- [ ] 同章点击定位到命中段落，Sheet 关闭。
- [ ] 搜索中可取消，不残留旧结果。
