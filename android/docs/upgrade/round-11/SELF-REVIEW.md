## 用户视角

**已改善**

1. 阅读器「更多 → 资料 → 搜索本书」可搜当前书正文。
2. 每条结果显示章节、前后文与关键词高亮。
3. 同章点击定位到命中段落；跨章跳到目标章（V1 限制）。
4. 顶部标注「搜索范围：译文/原文」，缺失自动回退。
5. 输入 300ms 防抖，关闭 Sheet 即取消。

**仍然存在**

- 跨章结果只到章首，需要再搜一次或手动翻。
- 没有搜索历史、没有模糊匹配、没有跨书搜索。
- 大章节逐段 `Paragraphs.split` 会有一次性开销（未做流式）。

## 设计师视角

**一致**

- 搜索 Sheet 与书签 Sheet 同一 BottomSheet 语言、同一纸色。
- 关键词只加粗 + 正文色，不新增背景色块。
- 空态、搜索中、无结果三种状态都有明确文案。
- 结果行点击区域整行，触控目标足够。

**取舍**

- 搜索结果不显示页码，只显示章节与片段：页码随字号/分页变化，容易误导。
- 高亮不做多色，避免在夜间纸色上刺眼。

## 工程师视角

**做对了**

- `findHits` 是纯函数，段落 ID 与阅读器 `Paragraphs.split` 同源。
- `BookSearchService` 逐章读取，命中到 30 条即停，不整本入内存。
- ViewModel 用 `searchJob.cancel()` 保证快速输入时不堆积任务。
- 搜索范围由 `displayMode` 决定，与阅读器显示一致。

**风险与限制**

- 跨章结果跳转后段落丢失：新章节从章首开始，V1 明确限制。
- 段落 ID 在重新翻译/原文刷新后可能漂移，搜索结果点击可能偏几段。
- 搜索只匹配第一个大小写不敏感位置（每段一条），同段多处不重复列出。

**未验证**

- 真机上 300ms 防抖与键盘遮挡（Sheet 有输入框，风险比书签 Sheet 高）。
- 300 章全本搜索的耗时与取消响应。
- 夜间纸色下高亮对比度（加粗 + 正文色，理论安全）。

## 结论

Round 11 目标达成，可作为 1.4.1 发布。排版与拖动进度留给 Round 12。
