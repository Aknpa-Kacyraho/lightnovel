# Round 5 · 用户视角升级指南（v1.2.1）

> 基线：1.2.0（versionCode 41）。Round 4 解决了阅读器自身刺眼与常驻提示。
> 本轮处理「回到书架/发现/任务页后，深色模式仍然晃眼」的问题。

## 1. 用户真实会遇到的 4 个问题

### U1. 深色模式下次要文字太亮（P0）

8 套深色主题的 `onSurfaceVariant`（作者、标签、说明文字）都在 `#C0C8C9` 以上，
对比度普遍 10–13:1。深色界面里，主文字与次要文字几乎一样亮：

- 书架每张卡的作者/进度（`LibraryScreen.kt:480-490`）
- 任务卡状态说明（`TaskCenterScreen.kt:273-282`）
- 设置页所有说明文字

**用户感受**：满屏亮字，分不清主次；夜里看久了眼睛累。

**本轮要求**：8 套深色主题的次要文字统一调暗到约 8:1，仍清晰可读；
主文字保持 ≥12:1。不改变浅色主题。

### U2. 深色下标签色块偏艳（P1）

`Theme.kt:45-47` 用 `lerp(surface, secondary/tertiary/error, 0.30f)` 生成深色容器色。
标签（题材/关键词/来源）在深色下变成一块块高饱和色，滚动时很跳。

**用户感受**：像贴了一排荧光贴纸，抢过书名。

**本轮要求**：深色容器混合比例从 0.30 降到 0.24，标签仍有区分度但不发光。
浅色保持 0.14。

### U3. 卡片与背景的边界靠亮线（P1）

深色下 `outlineVariant` 是 `lerp(surface, outline, 0.45)`，卡片描边接近中灰，
每张卡都有一圈亮边；书架、任务、设置三处重复。

**用户感受**：列表像一格格的框，视觉噪音大。

**本轮要求**：卡片统一使用 `surfaceContainerLow` 容器色，描边降到 `outlineVariant`
的 60% 透明度；只在需要分组的设置卡片保留完整描边。

### U4. 「继续阅读」卡没有进度（P2）

书架顶部横向卡片只有「第 N 话」，没有进度感；下方列表反而有进度条。
**记录到 Round 6**：与阅读进度细线一起做。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 深色下次要文字不再抢眼 | 8 套主题对比度 7–10:1 |
| U2 | 标签色块变柔和 | 目视 + 容器混合参数 |
| U3 | 卡片不再被亮边框包围 | 书架/任务卡描边变淡 |

## 3. 明确不做

- 不改浅色主题配色（已经比较克制）。
- 不改 8 套主题的 primary/secondary 色相，只调明度与容器混合。
- 不新增主题、不做自动换主题。
