# Round 30 · 用户视角升级指南（v1.9.3）

> 基线：1.9.2（versionCode 66）。本批回到 bug 修复，不新增功能、不改视觉。
> 目标是修掉「会丢数据 / 会卡住 / 会留下坏文件」的真实问题。

## 1. 用户真实会遇到的 4 个问题

### U1. 导入旧备份后，读到一半的进度回到第 1 话（P1，数据丢失）

用户把旧手机备份导进新手机，或重装后恢复备份；书架、书名都回来了，
但原本读到第 87 话的书变成「未读」，滚动位置也回到开头。

**根因线索**：旧备份的 `data/library.json` 里没有 `added_at`，也没有
`data/books/<id>.json` 阅读状态文件；导入时为这类书合成了一条
「更新时间 = 现在」的状态，覆盖了本机已有的进度。

**本轮要求**：备份没有某本书的状态文件时，不动本机现有进度；
新书才建立默认状态。重复导入必须幂等。

### U2. 导出备份/EPUB 失败后，文件管理器里留下打不开的坏文件（P2）

选择保存位置后导出，进度条走了一半报错；回到文件管理器，
能看到一个 0 字节或半截的 zip/epub，点开提示损坏。下次再导出同名文件还要先手动删。

**本轮要求**：导出失败或取消时，删除刚创建的目标文件；成功才保留。

### U3. 在任务中心取消翻译，回到阅读器仍显示「正在翻译」（P2，状态卡住）

用户在阅读器点翻译，等不及切到任务中心点「取消」，再回到阅读器：
顶部横幅还转着圈写「翻译中 3/20」，翻译菜单里的「翻译本章」是灰的，
只能再点一次「取消」或退出重进才恢复。

**本轮要求**：外部取消后，阅读器翻译状态立刻回到「已取消」，按钮恢复可用。

### U4. 某些 EPUB 导入后是一堆乱码，或章节顺序错乱（P2）

用户把 EPUB 改名成 `.txt`（或下载时丢了扩展名），导入后正文是乱码；
另一些 EPUB 的 `content.opf` 用单引号写 `idref`，导入后章节按文件名排序，
和书里的顺序不一致。

**本轮要求**：按文件头识别 EPUB，不只信扩展名；EPUB 的 spine 同时支持单双引号。

### 复审追加（数据层与阅读器）

#### U5. 换机恢复备份后，书签全部消失（P1）

备份只带书和进度，不带书签；恢复后书签列表是空的，用户以为书签被清掉了。

**本轮要求**：备份写入 `data/bookmarks.json`，导入按
`bookId + chapterIdx + paragraphId` 去重补齐；旧备份没有该文件时正常导入。

#### U6. 只加进书架、没下载过的书，恢复后整本消失（P1）

用户把书加入「想读」但没打开过，因此没有 `novels/<dir>` 目录；恢复备份时
只按目录建书，这本书和它的阅读状态一起消失。

**本轮要求**：从 `data/library.json` 恢复没有目录的书与状态；章节按需在线拉取。

#### U7. 「未译全」章节点重试没有反应（P1）

任务中心或章节页对 `partial` 章节点重试，协调器看到已有译文文件就直接跳过，
界面仍显示未译全，队列却把它算作完成。

**本轮要求**：只有 `complete`/无 sidecar 的章节才跳过；`partial` 真正重译。

#### U8. 旧备份的章节信息会让「润色本章」崩溃（P0）

旧备份的 `chapters/*.meta.json` 缺少当前 schema 字段；阅读时异常被吞掉，
点「润色本章」后在后台解码 sidecar 时抛异常，进程崩溃。

**本轮要求**：sidecar 解码失败视为「缺少翻译信息」，返回可读错误，不崩溃。

#### U9. 滚动模式下搜索/书签/模式切换位置偏移（P1）

在线抓取的正文与译文用单换行连接段落，滚动列表也是按行；
但「行号 ↔ 段号」换算假设每段后有一个空行。结果搜索跳转、书签定位、
翻页/滚动切换会偏移，长章节甚至跳到章末。

**本轮要求**：滚动列表按段落块生成，段间插入一个不占高度的分隔项，
让行号与段号严格对齐。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 重复导入不丢进度 | 无状态文件的旧备份导入后进度不变 |
| U2 | 失败不留坏文件 | 导出失败后目标 URI 被清理 |
| U3 | 取消后状态恢复 | 外部取消后横幅显示已取消，可再次翻译 |
| U4 | EPUB 识别更可靠 | `.txt` 的 EPUB 正常解析；单引号 spine 顺序正确 |
| U5 | 书签随备份恢复 | 导入后书签存在，重复导入不重复 |
| U6 | 未下载的书不消失 | 恢复后有书、有状态，章节按需下载 |
| U7 | 未译全可重试 | `partial` 章节真正进入翻译 |
| U8 | 旧备份不崩溃 | 坏 sidecar 只报错，不杀进程 |
| U9 | 滚动定位准确 | 单换行正文的搜索/书签/模式切换不偏移 |

## 3. 明确不做

- 不新增功能、不改信息架构与视觉。
- 不改备份格式版本（仍是 format 1）。
- 不重写翻译队列；只修状态与统计的边界。
