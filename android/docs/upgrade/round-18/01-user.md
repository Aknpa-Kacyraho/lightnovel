# Round 18 · 用户视角升级指南（v1.6.2）

> 基线：1.6.1（versionCode 54）。前两轮修了位置错位、加载竞态与跨章跳转。
> 本轮修「小但会累积」的问题：退出丢进度、筛选闪一下、书名翻译重复请求。

## 1. 用户真实会遇到的 3 个问题

### U1. 退出阅读器太快，最后翻的一页没记住（P1）

`onPageChanged` 用 `saveJob?.cancel()` 防抖写进度；退出阅读器时 ViewModel 被清空，
`viewModelScope` 取消，最后一页的写入可能没执行。

**用户感受**：看到第 80 页，退出再进来回到 79 页。

**本轮要求**：最后一次翻页的进度必须落盘，即使马上退出。

### U2. 切书架筛选时列表闪一下（P2）

书架下拉切换调用三次状态更新（shelf、收藏、已移出），每次都重建查询 Flow，
列表可能短暂显示中间状态。

**用户感受**：点「在读」，列表先闪一下再稳定。

**本轮要求**：一次切换只更新一次筛选状态，不产生中间态。

### U3. 书架反复请求书名翻译（P2）

`LibraryViewModel.init` 每次创建都会对缺中文标题的在线书调用
`translateTitles`；服务内部不查内存缓存，每次进入书架都可能重复请求。

**用户感受**：书名早就翻好了，后台还在偷偷发请求（耗流量/额度）。

**本轮要求**：同一批书在短时间内只请求一次；已有中文标题不再请求。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 退出不丢最后一页 | 翻页后立即退出，重进仍在最后一页 |
| U2 | 切换筛选不闪 | 下拉切换只触发一次查询 |
| U3 | 标题翻译不重复 | 连续进入书架不重复请求同一批书 |

## 3. 明确不做

- 不改进度保存的防抖策略（仍 120ms/单次取消）。
- 不改筛选 UI。
- 不重写元数据翻译管线。
