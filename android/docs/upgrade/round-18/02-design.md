# Round 18 · 设计师视角升级指南（v1.6.2）

> 目标：修复「退出丢进度」「筛选闪烁」「重复请求」，全部无视觉变化。

## 1. 设计问题

### D1. 进度保存的用户预期（P1）

用户不关心防抖，只关心「退出再进来还在原处」。任何优化都不能牺牲这条。

**方案**：最后一次翻页的写入不受 ViewModel 取消影响；不加「保存中」提示。

### D2. 筛选切换的原子性（P2）

一次用户操作应该产生一次结果。当前下拉切换触发三次状态更新，
列表可能短暂显示「收藏/已移出也清空」的中间态。

**方案**：ViewModel 提供一次 copy 的 `applyShelfFilter`；UI 只调用一次。
视觉与交互不变。

### D3. 后台请求的克制（P2）

书名翻译是隐式后台行为，用户看不到进度，只会在意「为什么还在请求」。
同一批书不应在短时间内重复请求。

**方案**：服务内部用 in-flight 标记 + 已有译文过滤；并发请求直接跳过，
不排队、不提示。

### D4. 不改的东西

- 书架筛选/排序 UI；
- 阅读器进度显示；
- 元数据翻译的 prompt 与缓存格式。

## 2. 验收

- [ ] 翻页后立即返回书架，重进阅读器仍在最后一页。
- [ ] 书架下拉切换只产生一次列表刷新（无中间态）。
- [ ] 连续两次进入书架，第二次不再请求同一批书的标题。
- [ ] 没有新增文案、按钮或 loading。
