# Round 13 · 用户视角升级指南（v1.5.0）

> 基线：1.4.2（versionCode 49）。书签、搜索、排版已就位。
> 本批三轮转向「简洁、沉浸、专有名词」；Round 13 先把「沉浸」做成真的。

## 1. 用户真实会遇到的 4 个问题

### U1. 沉浸模式只藏了 App 的栏，状态栏还在（P0）

`ReaderRoute.kt:373` 的沉浸只隐藏阅读器顶栏/底栏；系统状态栏（时间、电量）与
导航栏仍在。正文上方始终有一条不属于书的东西。

**用户感受**：点了「沉浸阅读」，还是不像一本书，像全屏 App。

**本轮要求**：沉浸时隐藏系统状态栏与导航栏；从边缘上滑可临时唤出；
退出沉浸（单击正文或底部按钮）立即恢复。

### U2. 阅读页常驻一行「语言 / 滚动 / 朗读」（P1）

`ReaderRoute.kt:440-490`：模式行常驻三个按钮。滚动/翻页是低频切换（大多数用户固定一种），
却和语言、朗读一样占一行。

**用户感受**：正文被顶下去一截；三个按钮里只有一个每天用。

**本轮要求**：模式行只保留「语言」与「朗读」；「滚动 / 翻页」收进「更多 → 阅读」组。
菜单文案显示当前模式（「翻页模式」/「滚动模式」）。

### U3. 菜单里有重复入口（P1）

「更多」已有「排版」（字号/行距/边距/段距四个滑块），但菜单顶部仍有
「字号 N · 减小 / 增大」两项。

**用户感受**：菜单越来越长，翻一屏才到底；同一个功能有两个入口。

**本轮要求**：移除菜单里的字号 ±；字号调整统一走「排版」。

### U4. 沉浸退出提示与系统栏恢复要一致（P2）

隐藏系统栏后，底部「退出沉浸」按钮会贴到屏幕底边；提示文字仍要可见。

**本轮要求**：提示文字与按钮保留 `navigationBarsPadding` 的语义间距（固定 12dp），
不因系统栏隐藏而贴边。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 沉浸是真全屏 | 状态栏/导航栏消失，上滑临时唤出 |
| U2 | 模式行只剩语言/朗读 | 滚动切换在菜单里，文案显示当前模式 |
| U3 | 菜单不再有字号± | 字号只在「排版」 |
| U4 | 沉浸退出按钮不贴边 | 底部 12dp 间距，提示可见 |

## 3. 明确不做

- 不做全屏手势翻页、不做边缘点击翻页。
- 不做自动隐藏工具栏（用户手动切换）。
- 不改分页、翻译、书签、搜索。
