# Round 13 · 设计师视角升级指南（v1.5.0）

> 目标：沉浸要「真的没有界面」，常驻控件要「每个都有用」。不新增页面。

## 1. 设计问题

### D1. 沉浸的边界（P0）

App 内 chrome 与系统栏是两层。只藏前者，用户仍能看到时间/电量/手势条，
沉浸感被打断。

**方案**：
- 进入沉浸：`WindowInsetsControllerCompat.hide(systemBars())`，
  `systemBarsBehavior = BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`；
- 退出：`show(systemBars())`；
- 离开阅读器（`onDispose`）必须恢复，避免把系统栏状态带到书架；
- 系统栏隐藏时 Compose 的 `statusBarsPadding/navigationBarsPadding` 会变为 0，
  正文自然扩展，不额外调整 layout。

### D2. 模式行的减法（P1）

模式行只保留「原文/译文/双语」与「朗读」：

- 语言是阅读内容的一部分，必须常驻；
- 朗读是高频辅助；
- 滚动/翻页是设置级偏好，进菜单。

菜单项文案用状态描述：「翻页模式」/「滚动模式」，点击切换；不显示「切换到…」。

### D3. 菜单的减法（P1）

移除字号 ± 两项。理由：排版 Sheet 已有 12–30 的连续滑块，菜单里的 ±1
既慢又重复。保留「切换纸色」（高频、无其他入口）。

菜单从 18 项降到 17 项（新增 1 项模式切换、移除 2 项字号）。

### D4. 沉浸提示（P2）

进入沉浸的 3 秒提示保留；底部「退出沉浸」按钮与提示文字距屏幕底 12dp，
不因系统栏隐藏而贴边。提示文案不变：「单击正文或点下方按钮退出沉浸」。

### D5. 一致性

- 系统栏图标颜色仍由纸色决定（`DisposableEffect(readerTheme)` 已有）；
- 沉浸与纸色切换可叠加：隐藏状态栏后切换纸色，图标颜色逻辑不受影响；
- 退出阅读器时同时恢复系统栏与图标颜色。

## 2. 验收

- [ ] 进入沉浸：状态栏与导航栏消失，正文上移；上滑边缘临时显示。
- [ ] 退出沉浸：系统栏立即恢复，图标颜色与纸色一致。
- [ ] 直接返回书架：系统栏已恢复。
- [ ] 模式行只有语言与朗读（查询模式下仍有 ◀ ▶）。
- [ ] 菜单无「字号 ±」，有「翻页模式/滚动模式」。
- [ ] 沉浸提示与退出按钮距底 12dp。
