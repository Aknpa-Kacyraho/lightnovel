# Round 29 · 用户视角升级指南（v1.9.2）

> 基线：1.9.1（versionCode 65）。前两轮统一了排版、圆角、书架与设置。
> 本轮回到阅读器本身：纸色、夜间对比、阅读器内的弹层。

## 1. 用户真实会遇到的 3 个视觉问题

### U1. 夜间模式黑得太硬，正文又偏白（P1）

夜间纸色是 `#121212`，正文 `#BDBAB2`，对比接近 10:1。短时间看很清晰，
但连续读半小时后，白字在黑底上会有「发光」感，眼睛更容易酸。

**用户感受**：夜里看久了刺眼，调低屏幕亮度又觉得字发灰。

**本轮要求**：夜间纸色改为暖灰黑，正文降低一档亮度，对比控制在 8:1 左右；
次要文字保持可读，不变成灰雾。

### U2. 纸白偏冷、护眼偏绿，像屏幕不像纸（P2）

纸白 `#FAFAF7` 是冷白，护眼 `#EFF6E9` 绿色饱和偏高。白天看像网页背景，
不像纸；护眼模式看久了会觉得「滤镜感」很重。

**用户感受**：纸白没有纸的暖意；护眼像给屏幕套了一层绿膜。

**本轮要求**：纸白改暖白（米白但不黄），护眼降低绿色饱和度，
正文用暖黑而不是纯黑。

### U3. 阅读器警告条在夜间是一块亮橙色（P2）

`StaleBanner` 的夜间颜色是硬编码 `#3B2A17` 底 + `#FFCC80` 字。它比纸色亮很多，
一出现就把注意力从正文拉走；而且不随四套纸色变化。

**用户感受**：只是想继续读，突然弹出一条很亮的橙色提示，像警告弹窗。

**本轮要求**：警告条从纸色派生：底色是纸色混一点琥珀，文字用低饱和琥珀；
夜间不发光，浅色不脏。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 夜间久读不刺眼 | 夜间对比约 8:1，背景不纯黑 |
| U2 | 纸色像纸 | 纸白偏暖、护眼不绿、正文暖黑 |
| U3 | 警告条不抢正文 | 底色随纸色，夜间不亮橙 |

## 3. 明确不做

- 不改阅读器字号/行距/分页逻辑。
- 不改翻译状态机与警告触发条件。
- 不新增纸色主题。
