# Round 29 · 设计师视角升级指南（v1.9.2）

> 目标：让四套纸色都像「纸」，让阅读器内的提示层不再像系统弹窗。

## 1. 设计问题

### D1. 夜间不是「黑底白字」，是「暖灰纸上的墨」（P1）

纯黑背景 + 高亮正文是屏幕的对比，不是纸的对比。夜间阅读应该降低整体亮度差，
用暖灰黑承托暖灰白，让眼睛在低光环境下不用频繁调节。

**方案**：

| 纸色 | 背景 | 正文 | 次要 |
| --- | --- | --- | --- |
| 纸白 | `#F8F5EE` | `#2A2824` | `#6E675C` |
| 米黄 | `#F3E9D2` | `#3A3226` | `#7A6A52` |
| 护眼 | `#EDF2E6` | `#22302A` | `#4F6B5D` |
| 夜间 | `#171614` | `#B8B3A8` | `#8F8A80` |

- 夜间正文从 `#BDBAB2` 降到 `#B8B3A8`，背景从纯黑提到暖灰黑；
- 纸白去掉冷蓝感，护眼降低绿色饱和；
- `danger` 保持现有值，保证错误可辨。

### D2. 警告条是「纸上的便签」，不是系统 Toast（P2）

`StaleBanner` 现在用两组硬编码颜色，夜间是亮橙。它应该像贴在纸上的便签：
底色只比纸深一点，文字是低饱和琥珀。

**方案**：

```kotlin
val warning = if (theme == NIGHT) Color(0xFFD9A45B) else Color(0xFF8A5A00)
val container = lerp(
    theme.background,
    warning,
    if (theme == NIGHT) 0.16f else 0.12f,
)
```

- 夜间对比约 8:1，浅色约 6:1；
- 不再硬编码 `#3B2A17` / `#FFF1DC`；
- 圆角用 `MaterialTheme.shapes.small`，与全局一致。

### D3. 阅读器弹层顶角与全局一致（P2）

Material3 的 `ModalBottomSheet` 默认顶角 28dp，而全局 `LnShapes.extraLarge`
是 20dp。阅读器里的「更多 / 排版 / 术语 / 书签 / 搜索」打开时，圆角比页面大一圈。

**方案**：所有阅读器 Sheet 统一
`shape = RoundedCornerShape(topStart = 20.dp, topEnd = 20.dp)`；
底层颜色继续用纸色 `theme.background`。

### D4. 不改的东西

- 字号、行距、边距、分页；
- 顶栏/底栏结构；
- 警告触发条件与文案；
- 其他页面的 Sheet（本轮只收阅读器）。

## 2. 验收

- [ ] 夜间模式背景不是纯黑，正文不刺眼；次要文字仍清晰。
- [ ] 纸白像暖纸，护眼没有明显绿膜。
- [ ] 警告条在四套纸色下都像「纸上的便签」。
- [ ] 阅读器 Sheet 顶角 20dp，与全局一致。
