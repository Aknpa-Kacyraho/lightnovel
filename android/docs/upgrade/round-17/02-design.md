# Round 17 · 设计师视角升级指南（v1.6.1）

> 目标：修复用户能感知的状态错乱；不改变布局与视觉。

## 1. 设计问题

### D1. 切换语言模式要「确认感」（P1）

快速切换原文/译文/双语时，当前实现可能先显示新内容、又跳回旧内容。
视觉上像闪烁。

**方案**：修复加载竞态后，旧请求直接丢弃；UI 不需要新增 loading（现有
`loading` 仅在首次加载时为 true，切换模式保持当前画面直到新内容写入）。
验收时连续快速切换 3 次，最终内容与最后一次选择一致。

### D2. 跨章跳转的「到达感」（P1）

从书签/搜索跨章跳转，现在只到章首。用户需要再次打开列表点一次，体验断裂。

**方案**：跳转意图随导航传递（内存 pending），目标章加载完成后自动定位到段落；
不新增 loading、不弹提示。若目标章加载失败，保留在章首，不反复重试。

### D3. 提示不排队（P2）

连续操作产生多条轻提示时，「新消息替换旧消息」比排队更符合直觉。

**方案**：`collectLatest`，新消息取消上一条的 1.5 秒计时；视觉不变。

### D4. 不改的东西

- 阅读器顶栏/底栏/菜单；
- 书签/搜索 Sheet 的布局；
- 进度、页码、翻译状态。

## 2. 验收

- [ ] 快速切换原文/译文/双语 3 次，最终显示最后一次选择。
- [ ] 跨章书签点击后，目标章自动落在书签段落。
- [ ] 跨章搜索点击后，目标章自动落在命中段落。
- [ ] 连续加两个书签，提示立即替换，不叠 3 秒。
- [ ] 目标章加载失败时停在章首，不循环跳转。
