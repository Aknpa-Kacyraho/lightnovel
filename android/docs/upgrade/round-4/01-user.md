# Round 4 · 用户视角升级指南（v1.2.0）

> 基线：1.1.1（versionCode 40）。本轮开始处理「读久了累」的问题，而不是功能缺失。
> 证据来自阅读器主题、状态横幅与设置默认值，不把设计稿当既成事实。

## 1. 用户真实会遇到的 5 个问题

### U1. 晚上从书架点进阅读器，先被白底闪一下（P0）

App 跟随系统进入深色模式后，书架是深色；阅读器纸色默认仍是「纸白」
`SettingsStore.kt:25`（`readerTheme = "paper"`），背景 `#FAFAF7`。
`ReaderRoute.kt:293` 直接用这个背景铺满全屏。

**用户感受**：眼睛刚适应暗环境，翻一章就被白屏刺一下；每次进阅读器都发生。

**本轮要求**：纸色增加「跟随系统」，并设为新安装默认；系统深色时自动用夜间纸色，
浅色时用纸白。已经手动选过纸色的用户保持原选择，不被改写。

### U2. 没翻译的章节，顶部一直挂一条横幅（P0）

`ReaderRoute.kt:787-795`：只要本章没译文，就显示「本章还没翻译」+「已开启阅读时自动翻译；
还没开始就点『立即翻译』」。自动翻译开启时，这条几乎每章都出现，直到预译追上。

**用户感受**：我只是想读，顶上一直有一块提示；关不掉，还占正文高度。

**本轮要求**：未翻译且没有进行中任务/失败/预译队列时，不显示这条横幅。
翻译进行中、失败、预译暂停/出错时仍然显示。手动翻译入口在「更多」菜单里，不受影响。

### U3. 夜间正文还是偏亮（P1）

夜间纸色正文 `#C8C5BE`（`ReaderTheme.kt:20`），在 `#121212` 背景上对比度接近 10:1。
白天看很舒服，关灯后长时间读会觉得字在发光。

**本轮要求**：夜间正文降到 `#BDBAB2` 左右，仍保持高对比（≥7:1），不改字号与行距。

### U4. 想换纸色，只能一项一项循环（P1）

阅读器「更多 → 切换纸色」每次只切到下一套（`ReaderRoute.kt:313-317`），
四套纸色要连点三次才能回到原处。

**本轮要求**：菜单里「切换纸色」保留；设置页纸色选择增加「跟随系统」，
成为 5 个可见选项，一眼可选。不改阅读器菜单结构。

### U5. 阅读页顶部有三层控件（P2，本轮只记录）

从上到下：书名栏 → 翻译状态横幅 → 语言/翻页/朗读行。三层都常驻时，正文可用高度被压缩。
**记录到 Round 6**：评估把「语言/翻页/朗读」收进底栏或更多菜单。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 深色系统下进入阅读器不再白屏 | 系统深色 + 新安装 → 阅读器背景为夜间色 |
| U2 | 未翻译章节不再常驻横幅 | 自动翻译开、未开始 → 无横幅；进行中 → 有横幅 |
| U3 | 夜间正文不刺眼 | 目视 + 对比度断言 |
| U4 | 设置页可直接选「跟随系统」 | 5 个纸色选项，选中态正确 |

## 3. 明确不做

- 不做亮度调节、不做暖色滤镜、不做护眼定时。
- 不删「朗读」「滚动/翻页」入口，不重排阅读器顶栏（Round 6 再评估）。
- 不改翻译管线、不改预译策略。
