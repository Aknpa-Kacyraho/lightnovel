# Round 4 · 设计师视角升级指南（v1.2.0）

> 目标：降低「进入阅读器」和「长时间阅读」两处的视觉冲击与噪声。
> 不新增页面、不换主题结构，只调整纸色默认值与状态提示的出现条件。

## 1. 设计问题

### D1. 纸色没有「跟随系统」这一项（P0）

`ReaderTheme` 只有 4 套固定纸色（纸白 / 米黄 / 护眼 / 夜间），设置页与阅读器菜单
都要求用户明确选一套。结果：深色 App + 纸白阅读器，亮度断层。

**方案**：

- `ReaderTheme` 增加 `AUTO`，标签「跟随系统」，**排在第一位**；
- 新安装默认 `auto`；已保存 `paper/sepia/green/night` 的用户保持原值；
- 设置页纸色 chips 从 4 个变 5 个，沿用 `BrandFilterChip` 与横向滚动；
- 阅读器「更多 → 切换纸色」按 auto → paper → sepia → green → night 循环，
  第一次点击从「跟随系统」变成显式「纸白」，行为可预期。

**视觉**：`AUTO` 不需要单独色块；chip 文案已足够。选中态沿用现有 primary 容器。

### D2. 静态提示占据了动态提示的位置（P0）

「本章还没翻译」是**状态说明**，不是**需要行动的结果**。它与「正在翻译 3/12 段」
「预译暂停」共用同一块横幅，导致真正需要看的进度被静态文案淹没。

**方案**：横幅只在以下情况出现：
- 正在翻译本章（有进度/任务）；
- 翻译失败或未译全；
- 预译队列运行中、暂停或出错；
- 有一次性消息（`translationState.message`）。

「本章还没翻译」「已开启自动翻译」「当前是原文模式」不再常驻。
用户想知道状态时，顶栏的翻译状态点仍然是入口。

### D3. 夜间正文过亮（P1）

`#C8C5BE` on `#121212` ≈ 10.4:1，超过「舒适阅读」需要的 7–9:1。
在完全 dark 的房间，正文边缘会出现光晕感。

**方案**：正文改为 `#BDBAB2`（≈ 9.1:1），次要文字 `#8E8B84` 保持不变；
危险色不变。只改 NIGHT，不改纸白/米黄/护眼。

### D4. 纸色选项的可发现性（P1）

设置页把纸色放在「阅读」分组中部，5 个 chip 一行放不下时要横滚；
「跟随系统」排第一，用户第一眼能看到。

**约束**：
- 不改设置分组顺序；
- chip 文案：跟随系统 / 纸白 / 米黄 / 护眼 / 夜间；
- 不加图标、不加预览色块。

### D5. 一致性

- 未翻译横幅的消失，不影响「更多 → 翻译本章」与「立即翻译」按钮；
- 夜间正文变色后，引用块/术语下划线/查询高亮都要重新检查对比度；
- 纸色切换仍即时生效，不重启。

## 2. 验收

- [ ] 系统深色 + 新安装，阅读器背景为 `#121212`；系统浅色为 `#FAFAF7`。
- [ ] 设置页可见 5 个纸色 chip，「跟随系统」选中态正确。
- [ ] 自动翻译开启、本章未开始：无横幅；点「翻译本章」后出现进行中横幅。
- [ ] 夜间正文与背景对比度 ≥7:1；术语下划线仍可见。
- [ ] 已存 `paper` 的老用户升级后仍是纸白，不被动切到夜间。
