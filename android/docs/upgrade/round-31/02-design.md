# Round 31 · 设计师视角升级指南（v1.9.4）

> 本批关注「信任」：恢复后数据要完整，失败后操作要可预期，
> 设置页要诚实反映当前状态，返回要符合用户的空间记忆。

## 1. 设计原则

### D1. 章节是书的骨架，不能只恢复有文件的章节（P1）

用户判断「书还在不在」看两件事：书名、目录。目录只剩 5 话，
即使书还在，也会认为数据损坏。恢复应以数据库的章节表为准，
文件只是正文；没有正文的章节保留为可下载的占位。
本地书没有源站，标题是唯一的身份信息，必须随备份保存。

**方案**：备份 `data/chapters.json` 保存 `bookId/idx/title/titleZh/status`；
导入时「已有优先、缺行补齐、空标题补全」。

### D2. 重试必须重试刚才失败的那件事（P1）

用户点「重试」时的心理模型是「再做一次刚才没成功的事」。
如果润色失败却触发整章翻译，既多花钱又破坏预期。
**方案**：失败时记录一个 retry action；横幅重试按 action 分派，
新操作开始时清空。

### D3. 设置页是「当前状态」，不是「打开时的快照」（P2）

阅读器和设置页共享同一份设置。设置页保留旧值会让用户怀疑
「我到底改成功了没有」，拖动旧滑杆还会覆盖新值。
**方案**：持续 collect `settingsStore.settings`，只同步已保存字段；
端点、模型、Key 输入框保留用户未保存的编辑。

### D4. 空态要说真话（P2）

「没有已移出的书」和「没有匹配的已移出书籍」是两种不同事实。
空态判断顺序应先看搜索/筛选，再看范围；清除筛选只清掉造成空结果的条件。
**方案**：`emptyShelfCopy` 先算 `hasFilter`；清除时若仍在「已移出」范围，
保留 `removedOnly`。

### D5. 失败必须在用户当前视野内可见（P2）

错误写到被 Sheet 遮住的主列表，等于没写。加书失败应显示在预览弹层内，
按钮保持可点，允许直接重试。

### D6. 返回栈要符合「替换」而不是「叠加」（P2）

从阅读器打开目录，是「离开当前章节去看目录」，不是「在章节上再叠一层」。
目录选章应替换旧 reader，返回直接回书架/任务/发现。

## 2. 验收

- [ ] 恢复在线书：目录行数与备份一致；未下载章节可后续下载。
- [ ] 恢复本地书：章节标题不是「第 N 话」。
- [ ] 润色失败 → 重试仍是润色；单段失败 → 重试仍是单段。
- [ ] 阅读器改字号/纸色 → 设置页立即同步，未保存的 Key 不丢。
- [ ] 已移出 + 搜索无结果 → 显示「没有匹配的已移出书籍」，清除后仍在已移出。
- [ ] 预览加书失败 → 弹层内显示错误。
- [ ] 目录选章 → 返回不经过旧章节阅读器。

## 3. 非目标

- 不改视觉 token、布局与文案风格。
- 不新增章节同步/源站刷新功能。
- 不改变备份 format 版本。
