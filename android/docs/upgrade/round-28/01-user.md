# Round 28 · 用户视角升级指南（v1.9.1）

> 基线：1.9.0（versionCode 64）。Round 27 统一了排版与圆角。
> 本轮处理「卡片海」：书架、发现、设置的信息密度与层级。

## 1. 用户真实会遇到的 3 个视觉问题

### U1. 书架像一列设置卡片，不像书单（P1）

每本书都是「卡片 + 描边 + 内边距 + 进度条」。十本书就是十个盒子，
封面、标题、作者被切成一格一格；浏览时眼睛先看到边框，再看到书。

**用户感受**：书架没有「逛书店/翻书单」的松弛感，像在看表格。

**本轮要求**：书架改为无卡片行：封面、书名、作者/进度直接落在页面上，
行与行之间用一条很淡的分隔线；进度用 2dp 细线，不用默认粗进度条。

### U2. 推荐卡封面比例不像书（P2）

推荐位封面 148×188，宽高比 0.79；搜索结果 64×88，比例 0.73。
真实书封接近 2:3（0.67），现在的封面偏方，像「内容卡片」而不是书。

**用户感受**：知道是书，但视觉上不像书架上的书；封面里的文字也被拉宽。

**本轮要求**：封面统一 2:3；推荐卡 140×210，结果卡 60×90。

### U3. 设置页七个大卡片堆在一起（P2）

外观、阅读、阅读翻译、翻译 API、数据、关于……每组一个 16dp 圆角卡片，
每组都有描边。设置页像仪表盘，分组层级靠「盒子」而不是标题。

**用户感受**：页面很满，找一个开关要在几个盒子里来回扫；看久了累。

**本轮要求**：设置改为「分组标题 + 行 + 细分隔线」；只有主题选择器
和备份提醒保留浅色底，不再每组一个描边卡片。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 书架像书单 | 行间只有淡分隔线，无卡片边框 |
| U2 | 封面像书 | 推荐/结果封面均为 2:3 |
| U3 | 设置层级靠标题 | 分组不再是大描边卡片 |

## 3. 明确不做

- 不改导航、路由、数据与交互逻辑。
- 不改主题配色与阅读器纸色。
- 不新增封面图片加载（仍是文字封面）。
