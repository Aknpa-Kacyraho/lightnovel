# Round 28 · 设计师视角升级指南（v1.9.1）

> 目标：把「卡片墙」降为「内容列表」；让书像书，让设置像设置。

## 1. 设计问题

### D1. 书架的第一视觉层应该是封面与书名（P1）

卡片边框、内边距、进度条同时在竞争注意力。书架的浏览行为是「扫封面、读书名」，
不是「读卡片」。去掉卡片后，行高与留白负责节奏，分隔线只负责边界。

**方案**：
- 行内边距：左右 16dp、上下 12dp；行高约 92dp。
- 封面 48×68（2:3）；书名 `titleMedium`，作者/进度一行 `bodySmall`。
- 进度：2dp 细线，颜色 `primary` 0.35；不要 Material 默认 4dp 圆角进度条。
- 分隔线：从封面右侧开始（start 76dp），`outlineVariant` 0.28，1dp。
- 列表 `contentPadding` 水平 0、垂直 8；`spacedBy(0)`。

### D2. 封面比例是「像书」的关键（P2）

2:3 是平装书的常见比例。推荐卡 140×210 在 148dp 列宽里略窄，但视觉更挺；
结果卡 60×90 与书架 48×72 同一比例，形成系统。

**方案**：
- `RecommendationCard`：宽度 140dp，封面 140×210；标题 2 行，作者/来源 1 行。
- `SourceResultCard`：封面 60×90；卡片内边距 12dp；标签最多 2 个 + `+N`。
- `BookCover` 的圆角已是 8dp，保持。

### D3. 设置页用「标题 + 行」建立层级（P2）

分组标题是设置的「章节名」，应该比行内容更醒目、更轻。卡片边框是多余的。

**方案**：
- `SettingsGroup` 改为 `Column`：标题 `labelLarge`、`primary`、上边距 20dp；
  内容行之间 `HorizontalDivider` 0.24；组与组之间 12dp。
- `highlighted`（备份提醒）用 `primaryContainer.copy(alpha = 0.35)` 的圆角底，
  只包内容，不包标题。
- 主题选择器保留独立卡片（它是视觉选择器，需要色块边界）。

### D4. 不改的东西

- 底栏、顶栏、导航结构；
- 书架筛选/排序控件；
- 发现页搜索框与来源筛选；
- 主题配色、阅读器纸色、文案。

## 2. 验收

- [ ] 书架连续 10 本书：没有卡片边框，分隔线只在行间。
- [ ] 推荐卡与结果卡封面均为 2:3；书名不被压扁。
- [ ] 设置页分组标题形成清晰章节感；没有 7 个大描边卡片。
- [ ] 深色主题下分隔线不发光，行与行仍可区分。
