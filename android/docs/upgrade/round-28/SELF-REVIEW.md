## 用户视角

**已改善**

1. 书架变成书单：没有卡片边框，行与行之间只有一条很淡的分隔线。
2. 封面统一 2:3：书架 48×72、推荐 140×210、搜索结果 60×90。
3. 搜索结果标签最多 2 个，其余显示 `+N`，不再挤成一行。
4. 设置页不再是一排描边卡片，分组标题承担层级。

**仍然存在**

- 深色主题下 0.28 的分隔线可能偏淡；需要真机逐套确认。
- 推荐卡变高后，横向列表整体高度增加；小屏上会挤压下方内容。
- 部分低频页面（目录/世界线）仍有自己的卡片样式，未在本轮统一。

## 设计师视角

**一致**

- 书架的第一视觉层回到封面与书名；分隔线只做边界。
- 2:3 封面比例让书架、推荐、结果三处形成同一套「书」的视觉。
- 设置页的分组标题用 `labelLarge` + primary，和行内容的层级拉开。

**取舍**

- 没有把书架做成双列网格：当前数据量与手机宽度下单列更易扫读。
- 没有给分隔线加渐变/阴影：越简单越不像模板。
- 主题选择器保留卡片：它需要色块边界，不能完全去容器。

## 工程师视角

**做对了**

- `BookRow` 从 `Card` 改为 `Column + Row + HorizontalDivider`，删除边框与背景。
- 进度线改为两层 `Box`（2dp），避免 Material3 进度条的停靠点。
- `LazyColumn` 改为垂直 8dp padding、0 spacing，行内 padding 负责节奏。
- 推荐/结果封面尺寸统一为 2:3；标签截断逻辑在 UI 层完成，不动数据。
- `SettingsGroup` 去 Card，保留 `highlighted` 的浅色底与滚动定位。

**风险与限制**

- `BookRow` 的菜单按钮仍在行右侧，触控目标 48dp；去掉卡片后点击区域仍是整行。
- `HorizontalDivider` 从 76dp 开始，封面较窄时视觉上仍对齐标题。
- `SettingsGroup` 的 `dataTop` 以组顶部为准，标题高度变化会影响滚动定位；
  当前只差 8dp，实测可接受。

**未验证**

- 真机截图、8 套主题、深浅色逐套检查。
- 小屏（360dp 宽）下推荐卡与结果卡的实际排版。
- 大字号系统设置下的行高。

## 结论

Round 28 目标达成，可作为 1.9.1 发布。阅读器纸色与 Sheet 圆角留给 Round 29。
