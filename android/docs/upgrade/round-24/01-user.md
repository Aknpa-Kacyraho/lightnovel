# Round 24 · 用户视角升级指南（v1.8.2）

> 基线：1.8.1（versionCode 60）。Round 16 修了滚动/翻页的进度存储，
> 但「切换模式」和「滚动模式下的书签」还有两处坐标混用。
> 本轮补齐，并把本地导入去重哈希写进备份。

## 1. 用户真实会遇到的 3 个问题

### U1. 滚动模式加书签，回到的是切换前的页（P1）

`currentAnchor()` 优先读取 `state.layout`（翻页模式的旧分页结果），
再判断是否滚动模式。用户从翻页切到滚动后，`layout` 仍然保留。

**用户感受**：在滚动模式读到第 80 行，加书签；打开书签却回到切滚动前的那一页；
切换原文/译文时也会跳回旧页。

**本轮要求**：滚动模式的锚点一律取当前滚动位置（行→段映射），
不再读旧的分页 layout。

### U2. 滚动 → 翻页 → 滚动，位置会跳错（P1）

`setReaderMode("page")` 把 `scrollParagraph`（行号）直接当成 `paragraphId`（段号）；
`setReaderMode("scroll")` 又反过来把段号直接塞给 `scrollParagraph`。

**用户感受**：滚动读到第 3 段，切翻页后跳到第 100 段/最后一页；
再切回滚动，列表滚到错误位置。

**本轮要求**：两个方向都走 `ReaderScrollMapping` 换算，位置保持不变。

### U3. 备份恢复后，再导入同一个本地文件会出现两本（P2）

本地导入用 SHA-256（`import_hash`）去重，但备份的 `library.json` 没写这个字段。
恢复备份后 `import_hash` 为 null，再导入同一个 TXT/EPUB 会被当成新书。

**用户感受**：换设备恢复备份，手滑再导入一次同一本书，书架出现两本一样的书，
阅读进度还分成两份。

**本轮要求**：备份写入 `import_hash`；恢复时带回；旧备份没有该字段时保持 null。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 滚动书签/切语言不跳页 | 滚动位置加书签，跳回同一段 |
| U2 | 跨模式位置一致 | 滚动→翻页→滚动回到同一段 |
| U3 | 恢复备份后去重仍有效 | 再导入同一文件提示「已在书架」 |

## 3. 明确不做

- 不重写分页/滚动渲染。
- 不改书签/搜索 UI。
- 不改本地导入的哈希算法与文件大小限制。
