# Round 24 · 设计师视角升级指南（v1.8.2）

> 目标：修两个「位置不可信」和一个「恢复后重复」的问题；界面不变。

## 1. 设计问题

### D1. 滚动模式的锚点必须来自滚动位置（P1）

滚动模式下，用户看到的当前位置就是 `scrollParagraph`（行）；
翻页模式留下的 `layout` 是旧视图的缓存，不应该参与当前锚点计算。

**方案**：`currentAnchor()` 先判断 `readerMode == "scroll"`，直接返回
当前滚动位置换算出的段号；翻页模式才读 `layout`。
书签、切换语言、翻译锚点都走同一个入口，行为自然一致。

### D2. 切换模式是一次「翻译」，不是「重置」（P1）

用户切模式是为了换一种阅读方式，不是想换一个位置。两个方向的坐标换算
必须对称，且不能改变用户所在的段落。

**方案**：滚动→翻页用 `currentParagraphIndex()`（行→段）；
翻页→滚动用 `lineForParagraph(...)`（段→行）。不新增动画或提示。

### D3. 恢复备份后，书还是「同一本」（P2）

本地导入去重依赖内容哈希。备份不写哈希，等于恢复后忘记了「这本书是从哪个文件来的」，
用户再次导入同一个文件时无法识别。

**方案**：备份 `library.json` 增加可选的 `import_hash`；导入时带回；
已有书保留现有哈希，旧备份没有字段时保持 null。不新增 UI。

### D4. 不改的东西

- 阅读器顶栏/底栏/菜单、书签/搜索 Sheet；
- 本地导入流程、文件选择器、去重提示；
- 备份 UI、manifest 格式与校验；
- 任何颜色、字号、间距。

## 2. 验收

- [ ] 翻页→滚动→加书签：书签预览是当前滚动段，跳回同一段。
- [ ] 滚动→翻页：落在同一段所在页，不是末页。
- [ ] 翻页→滚动：列表滚到同一段，不跳回旧位置。
- [ ] 导出→恢复→再导入同一 TXT：提示「已在书架」，不新增第二本。
- [ ] 没有新增可见控件或文案。
