# Round 14 · 设计师视角升级指南（v1.5.1）

> 目标：术语表从「能看」变成「能管理」。不加页面，不加新颜色。

## 1. 设计问题

### D1. 搜索框的位置（P0）

术语表顶部有三段说明文字、两个按钮、列表、添加表单。搜索框要放在**说明之后、
列表之前**，用户扫一眼就知道「这里能找」。

**方案**：
- `OutlinedTextField`，label「搜索术语」，singleLine；
- 搜索时列表只显示命中项，清空立即恢复；
- 无命中：「没有匹配的术语」；
- 搜索框不吸顶（页面本身可滚动），保持现有视觉节奏。

### D2. 条数与列表标题（P2）

**方案**：列表前加一行 `labelMedium`：
- 无搜索：`术语（共 N 条）`；
- 有搜索：`术语（N / 总数）`。

不新增按钮，不显示「已选」。

### D3. 覆盖提示（P1）

**方案**：当输入框原文与现有术语的 `source` 相同（trim 后完全一致），
在保存按钮上方显示：

```text
已存在同名术语，保存会覆盖译名。
```

用 `labelSmall` + `colorScheme.tertiary`；不弹窗、不阻止保存。

### D4. 删除确认（P1）

**方案**：点「删除」打开 `AlertDialog`：

```text
删除术语「アリス → 爱丽丝」？

删除后相关章节会标记过期，后续翻译不再锁定该译名。

[ 取消 ]  [ 删除 ]
```

「删除」用 `error` 色；列表项本身不显示删除图标（保持现有文字按钮）。

### D5. 不改的东西

- 术语添加表单（三个输入框 + 保存按钮）；
- 旧词库导入、更新章节资料、一致性检查；
- 人物卡、风格、前情三个 Tab；
- 术语的存储格式与翻译注入逻辑。

## 2. 验收

- [ ] 术语表出现搜索框；输入「爱丽丝」命中译名。
- [ ] 清空搜索恢复全部；无命中显示提示。
- [ ] 标题显示「共 N 条」；搜索时显示「N / 总数」。
- [ ] 输入已存在原文时出现覆盖提示。
- [ ] 删除先弹确认；取消不删，确认后列表更新。
