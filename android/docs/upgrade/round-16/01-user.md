# Round 16 · 用户视角升级指南（v1.6.0）

> 基线：1.5.2（versionCode 52）。本批三轮专注 bug 修复，不加新功能。
> Round 16 修「滚动模式的位置错位」——一个用户能明显感觉到、代码里确实存在的 bug。

## 1. 用户真实会遇到的 3 个问题

### U1. 滚动模式读到一半，切翻页模式会跳错位置（P0）

滚动阅读时，进度按「行号」保存（`ReaderViewModel.onScrollParagraphChanged`）；
翻页模式按「段落号」恢复（`pageForAnchor`）。两者混用同一个
`read_state.progress_block` 字段：

- 滚动读到第 40 行 → 存 `progress_block = 40`；
- 切到翻页模式 → 按「第 40 段」找页；实际这章可能只有 12 段 → 跳到末尾或错段。

**用户感受**：换个阅读模式，进度就丢了；再切回来也不对。

**本轮要求**：滚动模式保存**段号**，恢复时把段号换算成起始行号；
两种模式之间切换进度不丢。

### U2. 滚动模式加书签，位置是错的（P0）

`addBookmark()`（`ReaderViewModel.kt:379-386`）在滚动模式把
`scrollParagraph`（行号）当成 `paragraphId`：

- 预览取 `paragraphs.getOrNull(行号)`，可能越界或取到别的段；
- 书签列表显示的「第 N 话」正确，但跳转落到错误段落。

**用户感受**：书签加了个寂寞，点回去不是那句话。

**本轮要求**：书签存段号，预览与跳转都回到正确段落。

### U3. 滚动模式下点书签/搜索结果，列表不动（P1）

`ReaderScreen` 的滚动列表用 `rememberLazyListState` 初始索引；
`jumpToAnchor` 只更新 `state.scrollParagraph`，没有 effect 去滚动列表。

**用户感受**：点了书签，页面没反应，以为按钮坏了。

**本轮要求**：`scrollParagraph` 变化时滚动到对应行（同位置不重复滚）。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 跨模式进度一致 | 滚动→翻页→滚动，回到同一段 |
| U2 | 书签位置正确 | 滚动模式加书签，预览与跳转都对 |
| U3 | 滚动列表响应跳转 | 点书签/搜索后列表滚到目标行 |

## 3. 明确不做

- 不重写分页/滚动渲染。
- 不改数据库字段（`progress_block` 语义统一为段号）。
- 不新增书签/搜索功能。
