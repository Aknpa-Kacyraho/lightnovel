# Round 27 · 用户视角升级指南（v1.9.0）

> 基线：1.8.4（versionCode 63）。本批三轮专注视觉设计，先解决「看起来像默认模板」
> 和「长时间看眼睛累」的基础问题，不新增功能。

## 1. 用户真实会遇到的 3 个视觉问题

### U1. 每个页面的字号和行高都像各写各的（P1）

书架标题、设置分组标题、发现卡片标题、标签文字，大小和行距不统一：
有的标题偏大，有的正文行距偏紧，中文长句看起来「挤在一起」。

**用户感受**：页面之间切换时，文字节奏突然变化；看久了眼睛找不到稳定的阅读基线。

**本轮要求**：建立一套中文排版尺度，标题、正文、辅助、标签各有固定字号与行高；
页面只使用这套尺度，不再临时调字号。

### U2. 圆角大小混乱，卡片像同一个模板批量生成（P1）

封面 12dp、标签 8dp、筛选 chip 9dp、状态徽标 6dp、设置卡 16dp、提示条 10dp、
来源徽标 50dp。同一屏里出现五六种圆角，缺少统一的设计语言。

**用户感受**：说不上哪里怪，但就是「像 AI 拼出来的界面」，没有编辑过的痕迹。

**本轮要求**：定义 4/8/12/16/20 五档圆角；卡片统一 12、封面 8、标签 6、
按钮/chip 8、Sheet 20。来源徽标保留胶囊（它是唯一的例外）。

### U3. 描边太多太重，页面显得吵（P2）

书架每一行、设置每一组、章节每一块都是「卡片 + 1dp 描边」；描边透明度 0.6，
在浅色主题下形成一圈圈灰线。

**用户感受**：页面像表格，眼睛一直被线牵着走；长时间浏览容易疲劳。

**本轮要求**：列表卡片描边降到 0.35；能靠留白和底色分开的，不再加线。
不改变布局结构。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 全 App 排版节奏一致 | 标题/正文/标签字号行高来自同一套 token |
| U2 | 圆角有规律 | 同屏不再出现 9/10/14/16 混用 |
| U3 | 页面更安静 | 列表描边明显减淡，正文仍是第一视觉层 |

## 3. 明确不做

- 不改信息架构、页面结构与交互。
- 不改主题配色（放到后续轮次）。
- 不改阅读器纸色（放到后续轮次）。
