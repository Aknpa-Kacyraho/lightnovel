# Round 27 · 设计师视角升级指南（v1.9.0）

> 目标：建立一套克制、可复用的排版与形状语言；不靠装饰，靠尺度与留白。

## 1. 设计问题

### D1. 中文排版需要自己的行高（P1）

Material3 默认 `bodyLarge` 是 16sp/24sp（1.5），对中文长句偏紧；
默认 `titleLarge` 22sp 在手机列表中又偏大。中文需要更稳定的 1.6 倍行高，
标题则需要更克制的 20sp。

**方案**：定义 `LnTypography`：

| 角色 | 字号/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| `titleLarge` | 20/28 | SemiBold | 页面主标题 |
| `titleMedium` | 16/24 | Medium | 卡片/分组标题 |
| `titleSmall` | 14/20 | Medium | 列表主标题 |
| `bodyLarge` | 16/26 | Normal | 正文 |
| `bodyMedium` | 14/22 | Normal | 次要正文 |
| `bodySmall` | 13/20 | Normal | 辅助信息 |
| `labelLarge` | 13/18 | Medium | 按钮/标签 |
| `labelMedium` | 12/16 | Medium | 小标签 |
| `labelSmall` | 11/15 | Normal | 极小辅助 |

中文字距统一 0；不使用负字距。

### D2. 形状要有层级，不是越多越好（P1）

圆角应该表达「这个元素有多重」：封面/标签是轻量元素，圆角小；
Sheet 是临时层，圆角大。当前 9/10/14/16 混用没有语义。

**方案**：`LnShapes` 五档：

- `extraSmall` 4dp：状态徽标、内嵌小色块；
- `small` 8dp：封面、chip、按钮、提示条；
- `medium` 12dp：卡片、分组、列表容器；
- `large` 16dp：大卡片/弹层；
- `extraLarge` 20dp：BottomSheet 顶角。

标签专用 6dp（介于 4 与 8 之间），来源徽标保留 50dp 胶囊。

### D3. 层次靠留白与底色，不靠描边（P2）

卡片海 + 灰描边是「模板感」的主要来源。列表项之间用 12–16dp 留白和
更淡的分隔线；卡片只保留 0.35 透明度描边，作为边界提示，不是装饰。

**方案**：列表卡描边 `outlineVariant.copy(alpha = 0.35f)`；设置分组卡
`0.5f`；不再新增阴影。

### D4. 不改的东西

- 8 套主题的色相与命名；
- 页面结构、导航、阅读器排版；
- 任何文案；
- 阅读器纸色。

## 2. 验收

- [ ] 同屏不再出现 9/10/14/16dp 圆角混用。
- [ ] 标题、正文、标签的字号与行高来自同一套 Typography。
- [ ] 书架/设置/章节列表的描边明显变淡，但边界仍可辨。
- [ ] 深色主题下描边不发光、不抢正文。
