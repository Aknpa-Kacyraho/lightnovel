# Round 3 · 设计师视角升级指南（v1.1.1）

> 目标：让 App 在「极端条件」下仍然体面——大字体、横屏、平板、长章节。
> 不改变现有视觉语言，只补自适应规则。

## 1. 设计问题

### D1. 动作行没有换行策略（P1）

三处固定 `Row` 承担了会增长的内容：

- 任务卡动作行（查看 / 重试 / 取消 / 忽略），`TaskCenterScreen.kt:290-311`；
- 书架空态次级入口（导入备份 · 导入 TXT / EPUB），本轮新增；
- 任务筛选 chip 行已用横向滚动，可接受。

系统字体放大后，`Row` 不会换行，按钮会被压扁或文字截断。

**方案**：前两处改 `FlowRow`（`horizontalArrangement = spacedBy(4.dp)`），
按钮保持原样式；优先整行，放不下自动换行。筛选 chip 行继续横向滚动。

### D2. 横屏/平板一行太长（P1）

`ReaderRoute.kt:474-484` 用整个 `maxWidth` 减去左右 margin 计算排版宽度。
平板横屏下每行可达 40+ 汉字，阅读节奏被打断。

**方案**：翻页模式加最大阅读宽度 **680dp**，水平居中；左右留白由屏幕自然产生。
- 手机竖屏（<680dp）行为不变；
- 滚动模式本轮不改（记录到 Round 4）；
- 页码浮层仍按屏幕底部居中，不跟随正文宽度（现状可接受）。

### D3. 翻译动作没有规模提示（P1）

「翻译本章」和「重译本章」是同一个位置，但用户不知道这一章多长。
在菜单里补「（约 N 字）」，N 取当前章文本长度，四舍五入到百字：

- <1000 字：「约 800 字」；
- ≥1000 字：「约 1.2 千字」；
- 0 字（加载中）不显示括号。

不在按钮上显示价格；价格与模型相关，属于设置和费用确认页的职责。

### D4. 长章节加载像卡死（P2）

`ReaderRoute.kt:517-521` 只有转圈。超过 300ms 后补一行 `bodySmall`
「正在排版长章节…」，转圈保留。

**约束**：只在 `layout == null` 时显示；排版完成立即消失；不做假进度。

### D5. 弃用组件的视觉差异（P2）

`TabRow` 在 Material3 已弃用，建议 `PrimaryTabRow` / `SecondaryTabRow`。
两者指示器宽度不同（Primary 指示器与标签同宽）。章节列表与本书设定使用 TabRow，
切换后要目视检查指示器不压字、不跳动。

若视觉差异明显，保留 `TabRow` 并在 Round 4 统一主题化，不强行替换。

## 2. 约束

1. 不新增颜色、图标、依赖。
2. 680dp 是内容宽度上限，不是固定宽度；小屏不缩小。
3. `FlowRow` 换行后行间距 4dp，不改变按钮内部 padding。
4. 所有新文案 `bodySmall` / `onSurfaceVariant`，不抢正文。
5. 大字体验收：系统字体「最大」+ 显示大小「最大」，关键路径不截断。

## 3. 验收

- [ ] 任务卡四个动作在 1.5x 字体下换行且全部可点。
- [ ] 空态次级入口在 1.5x 下换行，不出现「导入 TXT / EP…」。
- [ ] 平板横屏正文不超过 680dp，居中，左右留白对称。
- [ ] 翻译菜单显示「约 N 字」，0 字时不显示。
- [ ] 超大章加载 300ms 后出现「正在排版长章节…」。
- [ ] TabRow 替换后指示器不压字；若不达标则回退并记录。
