# Round 33 · 用户视角指南（v1.9.6）

> 目标：只写用户能感知的问题，不写实现。
> 基线：1.9.5 / 69。数据恢复与阅读器主路径已稳定。

## 1. 本轮最想解决的 6 件事

### U1. 源站更新后，书架里的书看不到新章节

**现状**：书加入书架后，目录是加入当时的快照。源站后来更新了新章节，
书页仍显示旧章节数；退出重进也不会出现。用户只能删书重加，而删书会丢进度、
译文和书签。

**期望**：

- 打开书籍详情时自动检查一次源站目录。
- 有新章节时追加到目录末尾，并提示「目录已更新：新增 N 话」。
- 「更多」菜单里有明确的「同步目录」入口，可手动重试。
- 手动同步没有新章节时提示「目录已是最新，共 N 话」。
- 同步失败不影响已有目录阅读，只提示失败原因。
- 已有的阅读进度、译文、书签、下载文件一个都不能少。

### U2. 翻译失败后不知道为什么失败

**现状**：任务中心只显示「翻译失败，可重试」。用户不知道是没配 Key、
网络错误、被限流、返回格式不对，还是写盘失败，只能反复点重试。

**期望**：

- 失败任务卡直接显示最近一次失败原因（最多两行，可读）。
- 重试开始后旧原因消失；成功后不再显示。
- 重新打开 App 后原因仍在，不需要当场看到。

### U3. 翻译进行中看不到进度

**现状**：任务卡只显示「正在翻译」，长章节可能持续几分钟，用户无法判断
是在正常工作还是卡住了。

**期望**：

- 正在翻译且有进度时，显示一条细进度条和「已译 12/34 段」。
- 没有进度数据时仍显示「正在翻译」，不显示假进度。

### U4. 队列最后的错误被藏起来了

**现状**：后台预译队列失败时，队列行只显示暂停/进行中/完成数，看不到
最后一次错误。

**期望**：队列有错误时，在队列行下方显示简短原因，最多两行。

### U5. 阅读器里的人物下划线，读屏不认为是链接

**现状**：人物名有下划线、可点击，但 TalkBack 只把它当普通文字，
不会提示「链接」，也无法用链接导航方式跳转。

**期望**：读屏能识别为可点击链接，点击行为保持不变。

### U6. 目录/发现页的底部弹层圆角和阅读器不一致

**现状**：阅读器内弹层是 20dp 顶角，目录与发现页仍是 Material 默认 28dp。
同一个 App 里两种尺度。

**期望**：非阅读器弹层也统一 20dp，视觉上不再忽大忽小。

## 2. 明确不做

- 不删除源站已经下架的章节，也不按源站顺序重排本地章节。
- 不自动下载新章节正文，只在打开时按需下载。
- 不自动翻译新章节，避免未经确认消耗 API 额度。
- 不新增「强制覆盖完整译文」入口。
- 不做旧 `storageDir` 历史文件迁移。

## 3. 验收口径

| 场景 | 通过标准 |
| --- | --- |
| 源站新增 3 话 | 打开详情后目录多 3 话，提示新增 3 话，进度仍指向原章节 |
| 源站无变化 | 手动同步提示「已是最新」，不产生重复章节 |
| 源站少了几话 | 本地章节不删除，仍可阅读已下载内容 |
| 同步时断网 | 已有目录可读，提示同步失败，不崩溃 |
| 翻译失败 | 任务卡显示具体原因，重启后仍在 |
| 翻译进行中 | 有进度时显示 x/y 段，无进度时不编造 |
| 读屏 | 人物名被识别为链接，点击仍打开人物卡 |
| 视觉 | 目录/发现弹层顶角 20dp，与阅读器一致 |
