# Round 33 · 设计师视角指南（v1.9.6）

> 设计原则：目录是「补齐」不是「重置」；失败要可解释；进度要克制。
> 视觉延续 04-final.md，不新增卡片、描边、渐变或阴影。

## 1. 目录同步：把「补齐不是重置」延伸到源站

### 1.1 数据语义

- 本地章节 idx 代表源站位置，`idx = 1..N`。
- 同步只做两件事：
  1. 为 `1..源站章节数` 中本地缺失的位置补一行 `status = online`；
  2. 给本地标题为空的章节补标题。
- **绝不**：删除本地章节、改写已有标题、重排 idx、清空 `rawPath/zhPath`、
  改动 `read_state`。
- `books.episodes` 取「本地最大 idx」与「源站章节数」的较大值，避免源站
  暂时少几话时把书显示成变短。

### 1.2 交互

| 时机 | 行为 | 反馈 |
| --- | --- | --- |
| 进入书籍详情 | 静默强制拉一次目录并同步 | 有新增才用 Snackbar 提示；失败不打扰 |
| 手动「同步目录」 | 强制拉取并同步 | 总是给结果：新增 N 话 / 已是最新 / 失败原因 |
| 同步中 | 菜单项显示「同步中…」并禁用 | 防止连点 |

- 自动同步失败时保留缓存目录：页面照常显示，不出现整页错误。
- 同步成功后刷新 `state.chapters`、`book.episodes`、`readState`；
  当前筛选与搜索词保留。
- 新增章节的标题翻译在后台进行，失败不影响目录展示。

### 1.3 文案

- 菜单项：`同步目录`（不是「更新」，避免和 App 更新混淆）。
- 成功：`目录已更新：新增 3 话，共 128 话`。
- 无变化：`目录已是最新，共 128 话`。
- 失败：`目录同步失败：网络不可用`（原因截断到一行可读长度）。

## 2. 任务中心：让失败可解释、进度可感知

### 2.1 失败原因

- 失败/未译全任务卡在状态行下方增加一行原因，`bodySmall`，
  `onSurfaceVariant`，最多 2 行，超出省略。
- 原因来自最后一次真实失败：
  - `翻译异常：<异常信息>`；
  - `重译只完成了部分段落，已保留原完整译文`；
  - `写入失败：<异常信息>`；
  - 队列的「原文下载失败」「缺少原文」等。
- 重新开始翻译或成功提交时清空，不展示过期原因。
- 原因不进入备份，不改变备份格式。

### 2.2 进度

- 仅在 `status = translating` 且 `total > 0` 时显示：
  - 一条 2dp 高的 `LinearProgressIndicator`；
  - 右侧 `已译 12/34 段`，`labelSmall`。
- 没有 `total` 时只显示「正在翻译」，不显示 0% 或不确定动画，
  避免让用户误以为卡住。
- 进度条颜色用 `colorScheme.primary`，不新增颜色。

### 2.3 队列错误

- 队列行保持单行摘要；有 `lastError` 时在其下方增加一行，
  `labelSmall`、`colorScheme.error`，最多 2 行。
- 「停止本书」按钮位置不变。

## 3. 阅读器人物链接

- 视觉不变：下划线、颜色继承正文。
- 语义改为链接：读屏播报「链接」，支持链接导航。
- 点击后仍打开现有的人物卡，不新增弹层。

## 4. 底部弹层圆角

- 目录页 2 个、发现页 2 个 `ModalBottomSheet` 统一 `20dp` 顶角，
  与阅读器一致。
- 使用 `RoundedCornerShape(topStart = 20.dp, topEnd = 20.dp)`，
  不引入新的全局 token；`LnShapes.extraLarge` 当前即 20dp，
  但 Sheet 顶角语义独立，保持现有阅读器写法。

## 5. 不做的设计

- 不为「同步目录」新增独立卡片或 banner。
- 不在目录行上显示「NEW」角标：本轮没有可靠的首次出现时间。
- 不把失败原因做成可展开长文；两行足够定位问题。
- 不改任务中心的信息层级与筛选结构。

## 6. 设计验收

| 项 | 标准 |
| --- | --- |
| 目录 | 新增章节出现在末尾，已有章节顺序、标题、状态不变 |
| 反馈 | 自动同步只在有新增时提示；手动同步必有结果 |
| 失败原因 | 两行内可读，重试后消失 |
| 进度 | 有数据才显示，不出现假进度 |
| 一致性 | 弹层 20dp；颜色、字号全部走主题 token |
| 克制 | 不新增卡片海、不吃掉目录首屏空间 |
