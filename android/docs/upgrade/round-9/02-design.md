# Round 9 · 设计师视角升级指南（v1.3.2）

> 目标：把「删除」做成一个安全、清楚、只出现一次的动作。
> 不新增页面，不改书架卡片布局。

## 1. 设计问题

### D1. 删除必须是「有前提的」动作（P0）

书架卡片「⋮」现在只有「移出书架/移回书架」。
直接加「删除」会让在读的书也能一键清空，风险不可接受。

**方案**：
- 只在 `state.removedOnly == true` 时，卡片菜单显示「删除本地数据…」；
- 在读/想读/读完视图不显示该项；
- 删除入口用 `MaterialTheme.colorScheme.error` 文字，与普通菜单项区分。

### D2. 确认对话框要写清「删什么、不能恢复」（P0）

**方案**：

```text
删除《书名》的本地数据？

将删除：
· 正文与译文
· 世界线与资料库
· 阅读进度

删除后无法恢复。建议先在「设置 → 数据」导出备份。

[ 取消 ]  [ 删除 ]
```

- 标题 `titleMedium`，正文 `bodyMedium`；
- 「删除」按钮用 `error` 色（`ButtonDefaults.buttonColors(containerColor = error)`）；
- 「取消」是默认焦点，防止回车误删；
- 对话框可用返回键关闭。

### D3. 删除后书架立即消失（P1）

删除成功：书从「已移出」列表消失，Snackbar「已删除《书名》与本地文件」；
不需要跳到别的页面。删除失败：书保留，对话框关闭，Snackbar 显示错误原因。

### D4. 任务页不留空分组（P1）

删除后该书任务应从任务页消失。DAO 已有 `COALESCE(hidden,0)=0` 过滤，
但删除前需先停止队列，避免「删除后 worker 写回章节」。

### D5. 不改的东西

- 书架卡片、封面、进度线；
- 「移出」的 Snackbar 与撤销；
- 排序与筛选；
- 空态文案。

## 2. 验收

- [ ] 在「在读」视图打开卡片菜单，没有删除项。
- [ ] 在「已移出」视图有删除项，点击出现确认框。
- [ ] 确认框列出四类数据与「无法恢复」提示。
- [ ] 确认后书从列表消失，Snackbar 出现，存储目录被删。
- [ ] 删除过程中后台下载/翻译停止，任务页不出现该书。
