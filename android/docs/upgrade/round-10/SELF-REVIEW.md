## 用户视角

**已改善**

1. 阅读器「更多」可在当前位置添加书签；同一段重复添加不产生重复项。
2. 「书签列表」显示章节、40 字预览、相对时间；空态说明添加路径。
3. 同章书签点击回到原段落；跨章跳到目标章（V1 限制）。
4. 列表内可直接删除书签，误删可重新添加。

**仍然存在**

- 跨章书签只到章首，需要再点一次列表。
- 译文变化后段落 ID 可能漂移，书签会偏几段。
- 删除整本书时书签记录仍在 DB（书 id 不会复用，不影响使用，但占空间）。

## 设计师视角

**一致**

- 菜单新增两项，阅读组与资料组各一，组标题与顺序不变。
- Sheet 沿用阅读器纸色与 `ReaderTheme` 文字色，不新增颜色。
- 空态、相对时间、删除按钮都在一屏内；预览两行截断。
- 添加后 1.5 秒轻提示，不阻塞翻页。

**取舍**

- 「已添加书签」只改文案，不提供「点击移除」：移除统一在列表里，避免误删。
- 跨章不自动二次定位：需要新导航参数/全局锚点，V1 不做半成品。

## 工程师视角

**做对了**

- 书签主键 `(book, chapter, paragraph)`，重复添加是幂等 upsert。
- 同章跳转先写 `read_state` 再 `load()`，新锚点与 DB 进度一致。
- `relativeTime` 是纯函数，覆盖未来时间与非法输入。
- 菜单数据驱动，新增 action 只改一处 + 测试断言数量。

**风险与限制**

- 书签随书删除：`LibraryRepository.deleteBook` 的事务已包含 `deleteBookmarks`，
  不会留下孤儿记录。
- 段落 ID 依赖 `Paragraphs.split`；重新翻译后段落数变化会让旧书签偏移。
- `BookmarkSheet` 未做无障碍语义标注（列表项可点击但没有 role）。

**未验证**

- 真机上 Sheet 的高度与键盘遮挡（书签 Sheet 无输入框，风险低）。
- 同章跳转在长章节的定位准确度。
- 相对时间在非 UTC 时区的显示（测试固定 UTC）。

## 结论

Round 10 目标达成，可作为 1.4.0 发布。书内搜索留给 Round 11。
