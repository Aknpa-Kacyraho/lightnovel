# Round 10 · 设计师视角升级指南（v1.4.0）

> 目标：书签要「加得顺手、找得回来、看得懂」。不新增一级页面，不重排阅读器。

## 1. 设计问题

### D1. 添加书签不能打断阅读（P0）

阅读器菜单已经四组（阅读 / 翻译 / 资料 / 世界线），再加两项会变长。

**方案**：
- 「添加书签」放「阅读」组末尾，文案固定「添加书签」；
- 已存在于当前段落时，文案变「已添加书签」，点击不重复添加（或点击移除？V1 不做移除，
  避免误删；移除统一在列表里）；
- 不弹 Toast，用 1.5 秒的轻提示「已添加书签」或顶栏状态点闪烁——V1 用 Snackbar
  样式的轻提示，不阻塞翻页。

### D2. 书签列表用 BottomSheet（P1）

与「术语表」「附近词条」保持一致，不新开页面。

**方案**：

```text
书签
─────────────────────────────
第 3 话 · 雨夜的表白           ⋮ 删除
「……那句话我到现在还记得。」     2 天前
─────────────────────────────
第 12 话 · 旧校舍
「楼梯尽头有一扇不该存在的门。」   刚刚
```

- 章节标题用 `titleSmall`；
- 预览用 `bodySmall`，最多两行，`onSurfaceVariant`；
- 时间用 `labelSmall`，右对齐；
- 删除用图标按钮（`TextButton("删除")` 也可，V1 用文字，触控目标 ≥44dp）；
- 空态居中，`bodyMedium`。

### D3. 跳转后的落点要可见（P1）

同章跳转后，用户需要知道「到了」。V1 不做高亮动画，但：
- 跳转后关闭 Sheet；
- 页码/进度线立即变化；
- 若目标段落不在当前页，分页后定位到包含该段的页（现有锚点逻辑）。

### D4. 时间显示（P2）

相对时间：刚刚 / N 分钟前 / N 小时前 / N 天前 / 具体日期（>7 天）。
不在列表里显示完整 ISO 时间。

### D5. 不改的东西

- 阅读器顶栏/底栏/菜单分组；
- 阅读进度保存逻辑；
- 翻译状态横幅；
- 画布分页。

## 2. 验收

- [ ] 「更多 → 阅读」组出现「添加书签」，当前段已有书签时显示「已添加书签」。
- [ ] 添加后 1.5 秒轻提示，不遮挡正文超过一行。
- [ ] 书签列表显示章节、预览、相对时间、删除。
- [ ] 空态文案指向「更多 → 添加书签」。
- [ ] 同章跳转后页码变化正确，Sheet 关闭。
