# Round 10 · 用户视角升级指南（v1.4.0）

> 基线：1.3.2（versionCode 46）。书库与翻译问题已处理完毕。
> 本批三轮转向「阅读本身」：书签、书内搜索、排版与跳页。

## 1. 用户真实会遇到的 4 个问题

### U1. 读到重要段落，只能记住页码（P0）

阅读器只有阅读进度（`read_state.progress_idx/block/char`），没有书签。
用户想标记「这段伏笔」「这个设定」，只能退出、记住章节，或者截图。

**用户感受**：轻小说一卷几百页，回头找一句话像大海捞针。

**本轮要求**：阅读器「更多」菜单加「添加书签」与「书签列表」。
书签记录章节 + 段落 + 偏移 + 40 字预览；同一段重复添加不产生重复项；
书签列表可跳转、可删除。

### U2. 书签跳转不能只是「跳到章节开头」（P1）

只跳到章首等于没解决「找回那句话」。同章书签必须回到原段落；
跨章书签至少跳到目标章，并保留再次点击书签列表的入口。

**本轮要求**：同章书签点击 → 直接定位到原段落；跨章 → 先跳到目标章，
再从书签列表点一次即可定位（V1 明确限制，不假装完美）。

### U3. 书签列表没有上下文（P1）

只显示「第 3 章」无法判断是哪条书签。

**本轮要求**：每条显示「章节标题 · 40 字预览 · 添加时间（相对）」。
没有书签时给空态「还没有书签；阅读时点『更多 → 添加书签』」。

### U4. 书签不能清理（P2）

**本轮要求**：列表项右侧「删除」，点击即删（不需要二次确认，误删可重新添加）；
删除后列表立即更新。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 可添加/查看书签 | 添加后列表出现，重复添加不重复 |
| U2 | 同章书签回到原段落 | 点击后页码/段落正确 |
| U3 | 书签有章节与预览 | 列表信息完整，空态清楚 |
| U4 | 书签可删除 | 删除后列表即时更新 |

## 3. 明确不做

- 不做笔记/高亮/批注（书签先做扎实）。
- 不做跨设备同步。
- 不做书签导出（后续评估）。
