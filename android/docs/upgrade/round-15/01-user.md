# Round 15 · 用户视角升级指南（v1.5.2）

> 基线：1.5.1（versionCode 51）。沉浸与术语已处理。
> 本轮做「简洁好用」：把长条菜单与一排筛选 chips 收进该在的位置。

## 1. 用户真实会遇到的 4 个问题

### U1. 书架一行 7 个 chips（P1）

书架筛选行：全部 / 在读 / 想读 / 读完 / 收藏 / 已移出 / 排序。
小屏要横滚才能看全，而且「在读/想读/读完」三选一，本质是同一个维度。

**用户感受**：书还没找到，先在筛选上做选择题。

**本轮要求**：把三个书架状态收进一个「书架：全部/在读/想读/读完」下拉；
筛选行变成：书架 / 收藏 / 已移出 / 排序（4 个），小屏不用横滚也能看到。

### U2. 阅读器「更多」是长下拉（P1）

`TranslationMenu` 用 `DropdownMenu` 承载 16 项 + 4 个组标题。小屏上菜单会滚动，
组标题容易被裁在边缘，点击目标也偏小。

**用户感受**：想找「搜索本书」要滑两下；菜单像设置页。

**本轮要求**：改成底部 Sheet：组标题固定、项可滚动、最大高度约 70% 屏；
点击一项立即关闭。功能集合与顺序不变。

### U3. 设置页 7 组太长（P2，记录）

外观 / 阅读 / 阅读显示 / 翻译 API / 翻译 / 数据 / 关于。当前不做折叠，
先观察书架与菜单改完后的反馈。

### U4. 不改的东西

- 书架卡片、空态、搜索框；
- 阅读器菜单的功能与分组（只换容器）；
- 设置页结构。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 书架筛选 4 个 | 书架下拉含全部/在读/想读/读完 |
| U2 | 阅读器菜单是底部 Sheet | 分组标题完整、可滚动、点击关闭 |
| U3 | 功能不丢 | 16 项与顺序不变 |

## 3. 明确不做

- 不做设置页折叠/搜索。
- 不做发现页筛选折叠（下轮评估）。
- 不改筛选逻辑与排序逻辑。
