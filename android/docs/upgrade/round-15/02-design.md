# Round 15 · 设计师视角升级指南（v1.5.2）

> 目标：把「同维度选项」收进一个控件，把「长菜单」换成可滚动的 Sheet。

## 1. 设计问题

### D1. 书架筛选的维度（P1）

在读/想读/读完 是书架状态；收藏是布尔；已移出是可见性；排序是顺序。
四个维度混在一排 chip 里，用户要逐个读。

**方案**：
- 「书架：全部」chip 点击弹 `DropdownMenu`：全部 / 在读 / 想读 / 读完；
- 选中项打勾；chip 文案显示当前值（「书架：在读」）；
- 收藏 / 已移出 / 排序 保持现有 chip；
- 选「全部」等价于 `shelf = null`。

**布局**：4 个 chip，360dp 下预计能放下；放不下仍横滚，不强制换行。

### D2. 阅读器菜单的容器（P1）

16 项 + 4 个组标题 = 20 行。DropdownMenu 在手机上会滚动且没有固定标题。

**方案**：`ModalBottomSheet`：
- 顶部标题「更多」，`titleMedium`；
- 组标题 `labelMedium` + `primary`；分隔线保留；
- 菜单项 `bodyLarge`，左侧对齐，行高 48dp；
- 最大高度 `fillMaxHeight(0.7f)`，内部 `LazyColumn`；
- 点击一项：关闭 Sheet → 执行动作（与现有 `expanded = false` 一致）；
- 背景用阅读器纸色（`theme.background`），文字用 `theme.text`。

### D3. 触发按钮不变（P2）

顶栏「更多」`TextButton` 不变；只是点开后是 Sheet。

### D4. 一致性

- Sheet 的圆角、拖拽把手用 Material3 默认；
- 禁用项（翻译中/无译文）保持 `enabled = false`，颜色变淡；
- 书签/搜索/排版等 Sheet 不受影响。

## 2. 验收

- [ ] 书架筛选行 4 个控件；「书架：在读」下拉可切全部/在读/想读/读完。
- [ ] 切换后列表正确，搜索词与收藏不丢。
- [ ] 阅读器「更多」打开底部 Sheet，4 个组标题完整可见。
- [ ] 16 项顺序与功能不变；禁用项仍禁用。
- [ ] 点击任一项 Sheet 关闭并执行。
