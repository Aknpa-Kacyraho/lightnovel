# Round 12 · 用户视角升级指南（v1.4.2）

> 基线：1.4.1（versionCode 48）。Round 10 书签、Round 11 书内搜索已完成。
> 本轮处理「阅读中调排版」与「章节内快速跳转」。

## 1. 用户真实会遇到的 4 个问题

### U1. 阅读中调字号/行距要退出到设置（P0）

阅读器菜单只有字号 ±1 和切换纸色。行距、边距、段距只能去设置页改，
改完再回到阅读器，阅读位置还可能丢。

**用户感受**：白天在外面想调大字号、晚上想放宽行距，每次都要离开书。

**本轮要求**：阅读器「更多 → 排版」打开 BottomSheet，提供字号、行距、边距、段距
四个滑块与「恢复默认」；调整即时生效，位置保持。

### U2. 底栏进度只能看，不能拖（P1）

底栏是一条 2dp 进度线（Round 6），无法拖动。想从第 3 页跳到第 80 页只能连翻，
或者退出到目录。

**用户感受**：长章节翻到一半想回看，翻页翻到手酸。

**本轮要求**：翻页模式下进度线可拖动；拖动时显示「第 x / y 页」，松手跳转。
滚动模式本轮保持现状（说明原因：列表滚动定位与分页锚点不同）。

### U3. 排版调整后位置要保住（P1）

字号/行距/边距变化会重新分页。当前实现依赖 `anchorToRestore`，
但用户从 Sheet 里连续拖动时可能丢位置。

**本轮要求**：调整前后以当前页起始锚点恢复；连续拖动只在结束时重新分页（防抖）。

### U4. 恢复默认要一键（P2）

**本轮要求**：Sheet 底部「恢复默认」：字号 18、行距 1.7、边距 16、段距 8，
并持久化。

## 2. 本轮必须交付

| 编号 | 用户结果 | 验收 |
| --- | --- | --- |
| U1 | 阅读中可调四项排版 | Sheet 四个滑块即时生效 |
| U2 | 翻页模式可拖进度 | 拖动显示页码，松手跳转 |
| U3 | 调排版不丢位置 | 调整后仍在当前段落附近 |
| U4 | 一键恢复默认 | 四项回默认并保存 |

## 3. 明确不做

- 不做字体选择（已有设置页 serif/sans/mono）。
- 不做滚动模式拖拽跳转（下轮评估）。
- 不做排版主题预设（紧凑/舒适）。
