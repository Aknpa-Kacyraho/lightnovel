# Round 12 · 设计师视角升级指南（v1.4.2）

> 目标：把「排版」放进阅读，把「跳页」做得像翻书签。不新增页面。

## 1. 设计问题

### D1. 排版 Sheet 的层级（P0）

「更多」菜单已有 16 项；排版是高频调整，但不需要单独一级页面。

**方案**：BottomSheet，标题「排版」，四个滑块：

| 项 | 范围 | 默认 | 显示 |
| --- | --- | --- | --- |
| 字号 | 12–30 sp | 18 | 「18」 |
| 行距 | 1.2–2.4 | 1.7 | 「1.7」 |
| 左右边距 | 8–48 dp | 16 | 「16」 |
| 段落间距 | 0–32 dp | 8 | 「8」 |

- 滑块用 Material3 默认样式，`onSurfaceVariant` 标签；
- 值显示在右侧，`labelMedium`；
- 底部一行「恢复默认」（TextButton），右对齐；
- 不新增预览区（正文本身就是预览）。

### D2. 实时生效与防抖（P1）

拖动滑块时每次 `onValueChange` 都改状态会触发高频重新分页。

**方案**：
- 拖动中只更新本地 UI 值（Sheet 内 `remember` 状态）；
- `onValueChangeFinished` 才调 ViewModel setter；
- 字号/行距结束一次分页；连续调四项时逐项生效。

### D3. 底栏可拖进度（P1）

按「细线 + 小圆点」的视觉做，不引入 Material Slider 的大 thumb：

- 轨道 2dp，已读 `textColor 0.28`，未读 `textColor 0.10`；
- thumb 8dp 圆点，`textColor 0.7`；
- 拖动时在 thumb 上方显示「第 12 / 80 页」，`labelSmall`；
- 松手跳转，不改变底栏高度（24dp 触摸区，视觉仍细）。

### D4. 位置保持（P1）

调排版前列出当前页起始锚点，分页完成后按锚点恢复；
不要求「像素级不跳」，但必须回到同一段。

### D5. 滚动模式的说明（P2）

滚动模式不显示可拖进度（避免与列表滚动冲突）；底栏保留页码文字。

## 2. 验收

- [ ] 「更多 → 阅读」出现「排版」，Sheet 四个滑块与默认值正确。
- [ ] 拖动结束才重新分页，正文不会抖动。
- [ ] 调整后仍在当前段落附近。
- [ ] 「恢复默认」四项回默认并持久化。
- [ ] 翻页模式底栏可拖，拖动显示页码，松手跳转。
- [ ] 滚动模式底栏不出现可拖控件。
